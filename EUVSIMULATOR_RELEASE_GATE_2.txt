3. MATHEMATICAL VALIDATION
====================================================================

  ✅ HERMITIAN PROPERTY CONFIRMED:
    max|Im(S)| / max|Re(S)| = 9.89e-18  (pure rounding error)
    The double-sum is inherently real.  S.real is the exact intensity.
    S.real ≠ (S·S.conj()).real  → the old abs² was wrong.

  ✅ |I|² NEVER JUSTIFIED:
    The Hopkins double-sum IS the partially-coherent intensity.
    Applying |.|² would give I², which is not an intensity.
    (The |.|² belongs on each coherent source-point field in the Abbe
    method, but the Hopkins/TCC formulation already performs that sum.)

  ✅ SIGMA=0 GUARD CORRECT:
    |x| < 1e-15 catches only true x=0 (sigma=0 or dm=0).
    For sigma=1e-14, dm=1: x=2.9e-15, NOT caught (correctly computes TCC).
    No spurious triggering for nonzero sigma values.

  ✅ NILS FACTOR-2 CONFIRMED:
    For the pipeline configuration (full_chem, se_blur=10nm):
      Before: NILS ≈ 5.4   After: NILS ≈ 2.7   Ratio ≈ 2.0 ✓
    The theoretical ratio (log-slope doubling) is exactly 2.0;
    the measured CD may shift slightly, giving ~1.7-2.0× in practice.
