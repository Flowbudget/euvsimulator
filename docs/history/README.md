# Projekt-Historie: ausgelagerte Audit- und Arbeitsberichte

Repository-Stamm entfernt, um die Struktur auf den eigentlichen Quellcode zu konzentrieren.
Nichts davon ist verloren: jede Datei ist in der Git-Historie enthalten und kann mit

```bash
git show 85cbfa4:<pfad>        # z.B. git show 85cbfa4:STOCHASTIC_PHYSICS_DESIGN_AUDIT.txt
```

der Prüfbericht in [`audit_2026-09-04_vollpruefung.md`](../audit_2026-09-04_vollpruefung.md).

`references/**/README.md`- und `INDEX.md`-Dateien.
