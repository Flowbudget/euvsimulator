EUVSIMULATOR PHYSICS AUDIT
Step 1
Repository: euvsimulator
Date: 2026-08-19

EXECUTIVE SUMMARY

Complete physics audit of euvsimulator EUV lithography simulation pipeline.
12 core modules reviewed plus test suite.
20 physics domains evaluated against code implementation.
Key findings: 6 P0 critical issues, 11 P1 important issues, 8 P2 improvements, 4 P3 nice-to-have.
Most critical: double SE blur application, photon energy inconsistency, shot noise not dose-coupled,
CD extraction from aerial instead of developed resist, Dill parameter inconsistencies.

P0 - CRITICAL PHYSICS ISSUES

PRIORITY: P0
FILE: src/euvsimulator/aerial/abbe.py
FUNCTION: aerial_from_orders
LOCATION: Lines 243-244
CURRENT_BEHAVIOR: SE blur applied to aerial image before dose scaling
PHYSICS: Secondary-electron blur belongs in resist (photoelectron random walk), not in aerial optics

RECOMMENDATION: Remove se_blur_nm application from aerial_from_orders. Keep only in dose_to_acid

P1 - IMPORTANT MODEL ISSUES

ID: P1-001
PRIORITY: P1
FILE: src/euvsimulator/pipeline.py
FUNCTION: run_simulation
LOCATION: Line 536
CURRENT_BEHAVIOR: reflected_orders = (orders_te + orders_tm) / 2.0
PHYSICS: Unpolarized light = average of TE and TM intensities, not fields
UNITS: dimensionless (complex amplitude)
PROBLEM: Averaging complex fields instead of intensities |E|^2. Incorrect for unpolarized illumination
RECOMMENDATION: Compute intensity per polarization: (|orders_te|^2 + |orders_tm|^2) / 2
TEST_STATUS: tests/test_benchmarks.py tests TE/TM convergence but not unpolarized combination

ID: P1-002
PRIORITY: P1

LOCATION: Line 210
CURRENT_BEHAVIOR: Hard coherence cutoff if dm > coherence_orders + 1e-12
PHYSICS: TCC = 2*J1(x)/x damps gradually - no hard cutoff
UNITS: diffraction orders
PROBLEM: Double filtering - hard cutoff plus gradual TCC damping
RECOMMENDATION: Remove hard cutoff. Rely on TCC damping alone
TEST_STATUS: tests/test_reference_nils.py passes - reference model uses same cutoff

PHYSICS PIPELINE

1. Materials
   File: src/euvsimulator/materials.py
   Class: CXROTable
   Functions: refractive_index, get_f1f2, _load
   Equations: n=1-delta, k=(r0*lambda^2/2pi)*N*f2, delta=(r0*lambda^2/2pi)*N*f1
   Inputs: element symbol, energy [eV], optional density [g/cm3]
   Outputs: n, k (complex refractive index)
   Assumptions: CXRO data complete Z=1-92. Linear interpolation (log-log for f2)
   Simplifications: No temperature dependence. Fixed STP densities for gases
   Issues: P1-008 gas densities. P2: No validation of CSV integrity

2. Photon Energy
   File: src/euvsimulator/constants.py
   Functions: nm_to_eV, eV_to_nm
   Constants: EUV_WAVELENGTH_NM=13.5, EUV_ENERGY_EV=91.84
   Equation: E = h*c/lambda = PLANCK_EV*SPEED_OF_LIGHT/(lambda*1e-9)
   Issue: P0-003 nm_to_eV(13.5)=92.05 != 91.84 hardcoded. Inconsistent

3. Multilayer TMM
   File: src/euvsimulator/optics/tmm.py
   Functions: stack_smatrix, reflectivity, _kz, _admittance, _interface_smatrix, _layer_smatrix, _redheffer_star
   Equations: S-matrix Redheffer star product. Névot-Croce: r'=r*exp(-2*kz_a*kz_b*sigma^2)
   Inputs: n_layers [complex], thicknesses [m], wavelength [m], theta0 [rad], TE/TM, roughness_nm
   Outputs: R (intensity reflectivity), r (complex reflection coefficient)
   Issues: P1-009 Névot-Croce on both r_ab and r_ba. P1-010 roughness same for all interfaces

4. RCWA
   File: src/euvsimulator/mask3d/rcwa_torch.py
   Class: RCWA1D
   Functions: solve, permittivity_toeplitz, eigenvalue problem A = E - Kx^2 (TE), A = E - Kx*E^-1*Kx (TM)
   Inputs: eps_profile, thicknesses, period, lambda, theta, polarization
   Outputs: diffraction orders (complex amplitudes)
   Issues: P1-001 TE/TM field average. P1-010 single profile for all layers. P3-002 no 2D vector RCWA

5. Polarization
   Files: optics/tmm.py (_admittance), mask3d/rcwa_torch.py, pipeline.py
   Treatment: TMM: TE eta=kz/k0, TM eta=n^2*k0/kz. RCWA: separate TE/TM solvers
   Issue: P1-001 Pipeline averages fields not intensities for unpolarized light

6. Aerial Image
   File: src/euvsimulator/aerial/abbe.py
   Functions: aerial_from_orders, nils, abbe_image (legacy)
   Equation: Hopkins 1D: I(x)=sum_i sum_j r_i*r_j*TCC(i,j)*exp(i*2pi*(m_i-m_j)*x/Lambda)
   TCC: 2*J1(x)/x, x=pi*sigma*NA*dm*lambda/Lambda
   Inputs: complex orders, order_indices, period, NA, lambda, sigma, grid, focus, se_blur
   Outputs: aerial (GxG float64), NILS
   Issues: P0-001 double SE blur. P1-002 hard coherence cutoff

7. Partial Coherence
   Files: aerial/abbe.py (TCC), aerial/hopkins.py (TCC matrix + SOCS)
   TCC: 2*J1(x)/x (correct J1 not J0). Hopkins TCC via P_shifted @ diag(w) @ P_shifted^H
   Issues: P1-002 double coherence filtering. P2-001 illumination shapes incomplete. P2-002 source norm not verified

8. Secondary Electrons
   Files: aerial/abbe.py (_apply_se_blur), resist/exposure.py (gaussian_se_blur, dose_to_acid)
   Implementation: 2D Gaussian separable convolution. sigma_px = sigma_nm/dx
   Application points: 3 places - aerial (P0-001), dose_to_acid (P0-002), pipeline config
   Issue: P0-001/P0-002 double application. SE blur belongs in resist only

9. Photon Statistics
   File: src/euvsimulator/resist/stochastic.py
   Function: poisson_shot_noise, _generate_photon_shot_noise
   Conversion: photons_per_voxel = dose * voxel_area_cm2 * dose_to_energy_factor / photon_energy_eV
   Issue: P0-004 dose=None in pipeline. P2-007 voxel_area_cm2 hardcoded 1nm^2. P2-003 n_realisations=1

10. Resist
    File: src/euvsimulator/resist/exposure.py
    Functions: dill_abc_exposure, dose_to_acid, gaussian_se_blur
    Equations: Beer-Lambert: I(z)=I0*exp(-(A+B)*z). Acid=Q*(1-exp(-C*dose))
    Issues: P0-006 Dill C/Q inconsistencies. P1-005 A,B ignored in pipeline. P1-006 no depth absorption in main path

11. PEB
    File: src/euvsimulator/resist/peb.py
    Functions: reaction_diffusion_adi, reaction_diffusion_analytical, deprotection_fd, deprotection_analytical
    Equations: dA/dt = D*laplacian(A). dM/dt = -k*A*M
