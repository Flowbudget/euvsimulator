BIAS-MODEL CONSISTENCY: qualitativ konsistent, quantitativ
teilweise (bei großem N gut)
============================================================
  Modell: E[s²(N)] = σ²·(1 − 2/(N(N−1))·Σ_{i<j} rho(|i−j|)),
  σ² aus N=1024-Messung, empirisches rho:

  N =   64: model=0.0383  measured=0.0262  ratio=0.685
  N =  128: model=0.0530  measured=0.0465  ratio=0.877
  N =  256: model=0.0608  measured=0.0549  ratio=0.903
  N =  512: model=0.0644  measured=0.0605  ratio=0.940
  N = 1024: model=0.0662  measured=0.0679  ratio=1.026

  Befund:
  - Richtung und Form (monoton steigend, Sättigung) werden
    reproduziert.
  - Bei N ≥ 256 ist die Übereinstimmung gut (ratio 0.90–1.03).
  - Bei kleinen N (64, 128) unterschätzt das Modell den Bias
    (ratio 0.69–0.88): der gemessene Wert liegt UNTER der
    Modellvorhersage — d.h. der beobachtete Bias ist größer als
    das einfache Modell sagt. Konsistent mit Schätzrauschen bei
    N_eff = 1.5–2.5 und der langreichweitigen Korrelations-
    struktur (rho bis k≈56).
  - Das Modell ist NICHT auf die zwei Punkte (256, 1024)
    gestützt, sondern auf den vollen 5-Punkte-Scan.

WHAT IS ESTABLISHED
============================================================

    korreliert (rho(1)=0.9994; integrale Länge 7.76 nm).
  - Die effektive Stichprobengröße ist deutlich kleiner als die

    (N=1024) nm.
  - Der Korrelations-Bias erklärt die N-Abhängigkeit qualitativ

    einfache Modell).
  - Die Differenz Release vs. Großfeld ist bei gleichem N
    Null (t=−0.02) → kein Domänen-/BC-Effekt.
