B. LITERATURE REFERENCE
====================================================================

  Primary reference: Li (1996), "Use of Fourier series in the analysis of
  discontinuous periodic structures", J. Opt. Soc. Am. A 13(9), 1870–1876.

  Key result (Li 1996, Section 4, TM case):
  For the TM polarization, the field component H_y satisfies:
    ∂²H_y/∂z² + ε·∂/∂x·(1/ε)·∂H_y/∂x + k₀²·ε·H_y = 0

  The Fourier representation of the operator ε·∂/∂x·(1/ε)·∂/∂x requires
  Li's factorization rules:

  1. Inner product (1/ε)·∂H_y/∂x:
     This product is proportional to the tangential E_z field, which is
     continuous at material interfaces. Both factors (1/ε) and ∂H_y/∂x
     are discontinuous, but the PRODUCT is continuous.
     → Li's INVERSE RULE (Rule 2):
       FT[(1/ε)·∂H_y/∂x] = inv(Toeplitz(ε)) @ (-i·k₀·Kx·U)
       = inv(E_eps) @ (-i·k₀·Kx·U)

  2. Outer product ε·(result):
     The result of Step 1 is continuous (proportional to E_z). The factor
     ε is discontinuous, but the quantity it multiplies is continuous.
     → Li's LAURENT RULE (Rule 1):
       FT[ε·(continuous)] = Toeplitz(ε) @ (continuous)
       = E_eps @ (continuous)

  3. Full operator:
     FT[ε·∂/∂x·(1/ε)·∂H_y/∂x] = -k₀²·E_eps·Kx·inv(E_eps)·Kx·U

  Therefore:
    d²U/dz² + k₀²·(E_eps - E_eps·Kx·inv(E_eps)·Kx)·U = 0

  A_TM = E_eps - E_eps·Kx·inv(E_eps)·Kx

  Confirmed: This is EXACTLY the current implementation.

  Secondary reference: Lalanne & Morris (1996), "Highly improved convergence
  of the coupled-wave method for TM polarization", J. Opt. Soc. Am. A 13(4),
  779–784.

  Lalanne & Morris propose the formulation:
    A_TM = E_eps - Kx·inv(E_inv)·Kx
  where E_inv = Toeplitz(1/ε).

  This is DIFFERENT from the current implementation. The Lalanne formulation
  uses the Laurent rule for the inner product (E_inv = Toeplitz(1/ε) instead
  of inv(E_eps)), which is incorrect under the rigorous Li factorization.
  The Lalanne formulation gives the WRONG uniform-medium dispersion:
    q² = ε₀ - ε₀·sin²θ  (should be ε₀ - sin²θ)
  The error is (ε₀ — 1)·sin²θ, which is zero only at normal incidence.

  Tertiary reference: Moharam et al. (1995), J. Opt. Soc. Am. A 12(5),
  1077–1086. The original enhanced transmittance matrix formulation.
  Uses the Laurent rule for both products, which is known to be slowly
  convergent for TM. The Li formulation (current code) is the corrected
  version.


C. MATHEMATICAL DERIVATION — COMPLETE
====================================================================

  Starting from Maxwell's equations with exp(iωt):

  TM: H = (0, H_y, 0),  E = (E_x, 0, E_z)

  From ∇×H = iωε₀εE:
    ∂H_y/∂z = iωε₀ε·E_x   →   E_x = (1/(iωε₀))·(1/ε)·∂H_y/∂z
    -∂H_y/∂x = iωε₀ε·E_z   →   E_z = -(1/(iωε₀))·(1/ε)·∂H_y/∂x

  From ∇×E = -iωμ₀H (y-component):
    ∂E_x/∂z - ∂E_z/∂x = -iωμ₀·H_y

  Substituting and simplifying:
    ∂²H_y/∂z² + ε·∂/∂x·(1/ε)·∂H_y/∂x + k₀²·ε·H_y = 0

  Fourier expansion H_y(x,z) = Σ U_m(z)·exp(-i·k_xm·x):
    d²U/dz² + k₀²·A_TM·U = 0

  where A_TM = E_eps - E_eps·Kx·inv(E_eps)·Kx

  E_eps = Toeplitz(ε)  — Toeplitz matrix of the permittivity profile
  Kx = diag(k_xm/k₀)  — normalized diffraction wavevectors
  inv(E_eps) = inv(Toeplitz(ε))  — inverse of the Toeplitz matrix

  The operator E_eps·Kx·inv(E_eps)·Kx captures the Li-inverse-rule
  Fourier factorization of the TM operator. The outer E_eps factor
  comes from the Laurent rule applied to ε·(continuous), and the inner
  inv(E_eps) comes from the inverse rule applied to (1/ε)·∂H_y/∂x.

  Uniform-medium limit: E_eps = ε₀·I, inv(E_eps) = (1/ε₀)·I
    A = ε₀·I - ε₀·I·Kx·(1/ε₀)·I·Kx = ε₀·I - Kx²
    q² = ε₀ - sin²θ   ✓ (correct dispersion)


D. CANDIDATE COMPARISON
====================================================================

  Test: Binary grating (SiO₂, n=1.46, air, Λ=506.24nm, d=253.12nm, λ=632.8nm)

  | Formulation | Eigenvalue A | M=21 R₀ | M=151 R₀ | Slope | Correct uniform limit | Li-rule correct |
  |-------------|-------------|---------|----------|-------|---------------------|-----------------|
  | current     | E_eps − E_eps·Kx·inv(E_eps)·Kx | 0.1083 | 0.1621 | slow, monotonic | ✓ q²=ε₀−sin²θ | ✓ |
  | Li-inverse  | E_eps − inv(E_inv)·Kx·inv(E_eps)·Kx | 0.1071 | 0.1604 | ~same | ✓ q²=ε₀−sin²θ | Equivalent |
  | Lalanne     | E_eps − Kx·inv(E_inv)·Kx | 0.0027 | 0.0026 | fast, wrong | ✗ q²=ε₀−ε₀·sin²θ | ✗ |
  | old code    | E_inv − Kx·inv(E_inv)·Kx | 0.1307 | 0.1295 | stuck | ✗ q²=1/ε₀−sin²θ | ✗ |

  Key finding: The "current" and "Li-inverse" formulations are mathematically
  equivalent in the limit M → ∞. For a binary grating, the difference
  inv(E_inv) − E_eps = 0.108 (10.8% max element difference), but both
  formulations converge to the same limit (asymptotically).

  The "Li-inverse" formulation uses inv(E_inv) = inv(Toeplitz(1/ε)) as the
  outer factor. This is the rigorously correct application of Li's inverse
  rule for the outer ε factor. However, the outer factor in the operator
  ε·∂/∂x·(1/ε)·∂H_y/∂x acts on a CONTINUOUS quantity (E_z), so the
  Laurent rule (E_eps) is correct for the outer factor.

  The Li-inverse candidate would be correct if the outer quantity were
  discontinuous, which it is not. Therefore the current E_eps is the
  correct choice.

  The similarity of the convergence curves for current and Li-inverse
  confirms that they are asymptotically equivalent, differing only in
  the truncation error for finite M.


E. MODAL ADMITTANCE — CONFIRMED
====================================================================

  V_TM = E_eps @ W @ diag(1/q)

  Verified by:
  1. Interface matching: For a uniform medium, V = ε₀·(1/q)·I and
     Y_R = ε₀·k₀/kz = ε₀/q. The S-matrix gives A = V + Y_R·W =
     (ε₀/q + ε₀/q)·I = 2·(ε₀/q)·I, leading to S[0,0] = 0 (zero
     reflection at matched interface).

  2. Fresnel matching: At a bare substrate (n=1.46), the TM reflection
     coefficient matches the Fresnel r_p at all tested angles with
     diff < 1e-6.

  3. TMM verification: For absorbing slabs, the TM R₀ matches TMM
     with relative diff < 0.1% at all tested angles.

  The alternative V = E_inv @ W @ diag(q) (from field-continuity
  derivation) gives V = (1/ε₀)·q·I for a uniform medium, which gives
  A = (q/ε₀ + ε₀/q)·I ≠ 2·(ε₀/q)·I, leading to non-zero reflection at
  a matched interface. This is incorrect.

  The current V = E_eps @ W @ diag(1/q) is the correct modal admittance
  for the H_y-based TM formulation under the repository's S-matrix
  normalization convention.
