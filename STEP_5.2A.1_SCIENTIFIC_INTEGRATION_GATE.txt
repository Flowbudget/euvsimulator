CRITICAL QUESTION 1 — ler_estimate() SEMANTICS
============================================================

IMPLEMENTATION INSPECTED:

SIGNATURE:
def ler_estimate(
    developed,                           # 2D Tensor ODER Sequence[2D Tensor]
    threshold: float = 0.3,
    dx: float = 0.25,
    edge: str = "both",
    intensity = None,                    # einzelner Tensor ODER Sequence (gleichlange)
    estimator: str = "large_n",          # "large_n" | "corr_corrected"
    rho_truncation: int | None = None,
    seed_count: int | None = None
) -> LEREstimate

FINDINGS:

1. INPUT TYPE — "developed" akzeptiert:
   - EINEN 2D-Tensor (shape H×W) → wird zu Liste [tensor] gewandelt
   - ODER eine Sequence (list/tuple) von 2D-Tensoren gleicher Shape
   → JEDER Eintrag = EINE unabhängige Realisierung (ein Seed)

2. SEQUENCE SEMANTICS — Statistische Bedeutung:
   Jeder Eintrag der Sequence = EINE unabhängige Realisierung (ein Seed)
   Der Schätzer berechnet pro Realisierung EINEN LER-Wert (RMS über alle Zeilen dieses Feldes)
   Dann: ler_mean = mean(ler_per_real) → SE/CI aus Seed-Varianz
   Autokorrelation: gepoolt über ALLE Realisierungen (rho_pooled = mean(rho_i))

3. AGGREGATION: Ein LER pro Feld → dann Mean über Seeds
   KEINE Konkatenation der Zeilen, KEIN Mergen der Felder
   N_rows = fields[0].shape[0] (aus erstem Feld, alle gleich)

4. N_EFF Berechnung:
   N_rows = fields[0].shape[0] (pro Realisierung identisch)
   Autokorrelation rho(k) wird über alle Realisierungen GEPOOLT (mean)
   L_int = 0.5 + Σ rho(k) für k=1..K_trunc (rho<0.05, cap 200)
   N_eff = N_rows / (1 + 2·Σ(1-k/N)·rho(k))

5. SE/CI: Aus Seed-Varianz (vals.std()/sqrt(n_seeds))
   seed_count = len(vals) (Anzahl Realisierungen mit gültigen Kanten)
   uncertainty_nm = SE, CI95 = mean ± 1.96·SE

6. INTENSITY: Unterstützt gleiche Shape/Sequenz-Semantik wie developed

5. EDGE SEMANTICS:
   edge="both" (Default): RMS über left+right Deviations kombiniert (wie extract_ler default)
   edge="left"/"right": Einzelkante
   Production verwendet extract_ler mit Default edge="both" (Zeile 332-337)
   → Wechsel zu edge="left" ÄNDERT die Observable!
   Wissenschaftlich: "both" = kombinierte LER beider Kanten; "left" = nur linke Kante
   → KEIN Äquivalent; muss bei "both" bleiben für Produktionsäquivalenz

CRITICAL QUESTION 3 — SEED / LER AGGREGATION HIERARCHY
============================================================

CURRENT PRODUCTION:
  Seed-Loop (stochastic_n_realisations)
      ↓
  extract_ler() pro Seed
      ↓
  LER pro Seed
      ↓
  mean über Seeds

ler_estimate() IMPLEMENTATION:
  Sequence von Feldern (pro Seed eines Feldes)
      ↓
  EIN LER pro Feld (RMS über ALLE Zeilen des Feldes)
      ↓
  Mean über Seeds + SE/CI aus Seed-Varianz
      ↓
  Autokorrelation gepoolt über ALLE Realisierungen

OPTION A (Empfohlen):
  1 großes stochastisches Feld pro Seed (z.B. 256×2048)
      ↓
  ler_estimate() pro Seed (EIN Feld pro Seed)
      ↓
  LER pro Seed + N_eff pro Seed
      ↓
  Aggregate über Seeds (Mean, SE, CI)

OPTION B (FALSCH):
  Mehrere kleine Felder pro Seed kombinieren
  → N_eff würde künstlich aufgebläht

OPTION C (FALSCH):
  Ein Seed, ein riesiges Feld (256×2048)
  → KEINE Seed-Varianz → KEINE Unsicherheitsschätzung
  → Nur EINE Realisierung → keine statistische Validierung

GRUND FÜR OPTION A:
- Der Schätzer ler_estimate() erwartet EINE Realisierung = EIN Feld
- N_eff wird AUS der Autokorrelation DIESES Feldes berechnet
- Seed-Varianz liefert die Unsicherheit des MITTELWERTS
- Hierarchie: Spatial correlation (within field) → N_eff
                        Seed variation (between fields) → Uncertainty
- Das ist die einzig statistisch korrekte Hierarchie

TILING ANALYSIS — DETERMINISTIC vs STOCHASTIC
============================================================

DETERMINISTISCHES TILING (STEP 4.1):
  aerial_large = tile(aerial_256, (16, 4))
  → Gültig: deterministisches Feld ist periodisch
  → Blur(aerial_large) == tile(Blur(aerial_256))  (bitweise)

STOCHASTISCHES TILING:
  acid_large = tile(acid_256, (16, 4))
  → Rauschen wird exakt kopiert (16× periodisch in y)
  → rho(256) = 1.0, rho(512) = 1.0, ...
  → N_eff = N / (1 + 2·Σ(1-k/N)·rho(k)) ≈ N / (1 + 2·16·1) ≈ 0
  → KEINE zusätzlichen unabhängigen Samples

STOCHASTISCHE GENERIERUNG AUF GROSSFELD:
  aerial_large = tile(aerial_256, (16, 4))  # deterministisch tiling
  dose_map_large = aerial_large * dose
  acid_large = photon_deposition_shot_noise(dose_map_large, ...)
  → JEDE 256er-Periode hat EIGENES Rauschen (Poisson neu)
  → Rauschen ist NICHT periodisch (außer durch Blur am Rand)
  → N_eff wächst mit echter Feldlänge

FAZIT: Tiling des DETERMINISTISCHEN Aerial-Feldes VOR dem Rauschen = GÜLTIG
        Tiling des STOCHASTISCHEN Feldes = UNGÜLTIG
