VERDICT: CONFIRMED BUG
====================================================================

  The pipeline averages COMPLEX DIFFRACTION FIELDS instead of
  INTENSITIES for unpolarized TE/TM illumination.  This produces
  a spurious cross-term between orthogonal polarization states
  that does not exist in physical unpolarized light.


CURRENT BEHAVIOR
====================================================================

  pipeline.py, line 676:
    reflected_orders = (orders_te + orders_tm) / 2.0

  This computes the arithmetic mean of the COMPLEX field amplitudes
  from the TE and TM RCWA solves.  The resulting complex vector is
  then passed to aerial_from_orders() which computes:

    I_field(x) = Σ_i Σ_j  r_avg_i · conj(r_avg_j) · TCC(i,j) · exp(...)

  where r_avg = (r_TE + r_TM) / 2.

  Mathematically:
    I_field = |(r_TE + r_TM)/2|²  (with TCC weighting)
           = (|r_TE|² + |r_TM|²)/4  +  Re(r_TE·conj(r_TM))/2


PHYSICALLY CORRECT BEHAVIOR
====================================================================

  For UNPOLARIZED illumination, TE and TM are orthogonal polarization
  states that do not interfere.  The correct intensity is:

    I_correct(x) = (I_TE(x) + I_TM(x)) / 2

  where:
    I_TE(x) = Σ_i Σ_j  r_TE_i · conj(r_TE_j) · TCC(i,j) · exp(...)
    I_TM(x) = Σ_i Σ_j  r_TM_i · conj(r_TM_j) · TCC(i,j) · exp(...)

  The averaging happens AFTER the quadratic (aerial) reconstruction,
  because the TCC operates on the coherency matrix of each polarization
  separately.  This yields:

    I_correct = (|r_TE|² + |r_TM|²)/2    (averaged with TCC weighting)


DIFFERENCE (THE BUG)
====================================================================

  I_field - I_correct = -|r_TE - r_TM|² / 4

  This is always ≤ 0, and strictly < 0 whenever TE ≠ TM.
  The field average SYSTEMATICALLY UNDERESTIMATES the unpolarized
  aerial intensity by a spurious cross-term that physically does
  not exist — it treats TE and TM as if they were coherent.

  The error magnitude depends on the TE/TM difference:
    |r_TE - r_TM|² / 4  (per order pair)

REQUIRED FIX
====================================================================

  In pipeline.py, replace:

    # Line 675-676 — CURRENT (WRONG)
    orders_field = (orders_te + orders_tm) / 2.0
    aerial = aerial_from_orders(orders_field, ...)

  with:

    # CORRECT: compute aerials separately, then average intensities
    aerial_te = aerial_from_orders(orders_te, ...)
    aerial_tm = aerial_from_orders(orders_tm, ...)
    aerial = (aerial_te + aerial_tm) / 2.0   # ← average AFTER reconstruction

  This means:
  1. Run aerial_from_orders() twice (once for TE, once for TM)
  2. Average the resulting 2D intensity maps
  3. Proceed with dose multiplication → resist

  The cost: one additional aerial reconstruction (negligible for production).
  The fix is localized: only affects lines 675–710 of pipeline.py.
  RCWA solver calls (x2) remain unchanged — we already compute both TE and TM.

  API impact: NONE — SimulationResult stored fields are unchanged.
  RCWA impact: NONE — rcwa_torch.py is NOT touched.
