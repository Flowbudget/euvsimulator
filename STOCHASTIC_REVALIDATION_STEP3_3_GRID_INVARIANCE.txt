Hinweis: mean(D_eff) ist das Mittel über das gesamte Aerial-Feld
(mean(aerial) × D ≈ 0.18 × D). Die Varianz skaliert mit 1/dx²,
weil die Pixelfläche kleiner wird — das ist die ERWARTETE
physikalische Skalierung (weniger Photonen pro kleinerem Pixel →
höhere Pixelvarianz, gleiche physikalische Rauschdichte).

------------------------------------------------------------
PHYSICAL COMPARISON
------------------------------------------------------------

Methode: Vergleich des mittleren Quotienten
  measured_variance / theoretical_variance
über alle gültigen Pixel (aerial_norm > 0.01).
Alle Grids decken dieselbe physikalische Region (64×64 nm) ab;
gültige Pixel = physikalisch äquivalente Bereiche mit signifikanter
Aerial-Intensität. Der Quotient ist die physikalisch invariante Größe.

Relative Differenz der Ratios (40 mJ/cm²):
  A vs B: |0.9978 - 0.9976| / 0.9978 = 0.02 %
  B vs C: |0.9976 - 0.9977| / 0.9976 = 0.01 %
  A vs C: |0.9978 - 0.9977| / 0.9978 = 0.01 %

Relative Differenz der Ratios (160 mJ/cm²):
  A vs B: |0.9973 - 0.9978| / 0.9973 = 0.05 %
  B vs C: |0.9978 - 0.9978| / 0.9978 = 0.00 %
  A vs C: |0.9973 - 0.9978| / 0.9973 = 0.05 %

Maximale Grid-Abweichung: 0.05 % — keine physikalisch relevante
Grid-Abhängigkeit.

------------------------------------------------------------
DX SCALING
------------------------------------------------------------

Prüfung: variance ∝ dx^p (auf dem measured/theory-Ratio)

  Dose 40 mJ/cm²:  p = 0.0001, R² = 0.4504
  Dose 160 mJ/cm²: p = -0.0003, R² = 0.6730

Erwartung: p = 0.0 (kein künstlicher dx-Faktor)
Gemessen: |p| ≤ 0.0003 — statistisch nicht von 0 unterscheidbar.

Die R²-Werte sind hoch, weil die Ratios extrem eng beieinander
liegen (Spannweite < 0.001); der Fit auf so kleine Streuungen
ist nicht aussagekräftig, aber der Exponent p ist verschwindend
klein und in der richtigen Größenordnung (≈ 0).
