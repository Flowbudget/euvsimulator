TEST 3 – SIGMA=0 TCC EDGE CASE
============================================================

FINDINGS:
- Current code: x = π·σ·NA·dm·λ/Λ, TCC = 2·J1(x)/x
- At σ=0: x=0, J1(0)=0 → Division by zero → NaN
- Physical limit: σ→0 = fully coherent → TCC=1 for ALL dm
- Limit x→0: 2·J1(x)/x → 1 (since J1(x) ~ x/2)
- Code crashes at sigma=0 with float division by zero

CONFIDENCE: HIGH (simple mathematical fact)
PRIORITY: P1 – EDGE CASE BUG

RECOMMENDED FIX:
In aerial/abbe.py line 209-210:
```python
if dm == 0:
    tcc = 1.0
else:
    x = math.pi * sigma * na * dm * wavelength_m / period_m
    if x < 1e-12:  # sigma=0 limit
        tcc = 1.0
    else:
        tcc = 2.0 * _j1(x) / x
```

TEST 5 – STOCHASTIC SCALING TEST
============================================================

CRITICAL FINDING: LER INCREASES WITH DOSE (WRONG SCALING)

Full pipeline results:
| Dose (mJ/cm²) | LER (nm) | Photons/voxel | Mean acid count |
|---------------|----------|---------------|-----------------|
| 10            | 0.0099   | 0.24          | 0.0096          |
| 20            | 0.0190   | 0.48          | 0.0192          |
| 40            | 0.0258   | 0.96          | 0.0384          |
| 80            | 0.0378   | 1.91          | 0.076           |
| 160           | 0.0557   | 3.82          | 0.15            |
| 320           | 0.0824   | 7.65          | 0.31            |

Expected shot noise scaling: LER ∝ 1/√N_photons ∝ 1/√dose
Observed: LER ∝ √dose (OPPOSITE!)

Direct stochastic function test (with correct acid-dose coupling):
| Dose factor | LER | Expected (1/√dose) | Ratio |
|-------------|-----|--------------------|-------|
| 1           | 0.001985 | 0.001985         | 1.00 |
| 2           | 0.003942 | 0.001404         | 2.81 |
| 5           | 0.008414 | 0.000888         | 9.47 |
| 10          | 0.012905 | 0.000628         | 20.5 |

ROOT CAUSE IN poisson_shot_noise():
When dose is provided:
1. photons_per_voxel = dose × voxel_area × dose_to_energy / E_photon
2. lam = photons_per_voxel × QE  (mean acid molecule COUNT)
3. noisy_count ~ Poisson(lam)
4. noisy_acid = acid × (noisy_count / lam.clamp(min=1e-30))

PROBLEM: When lam << 1 (typical for 0.1875 nm grid):
- noisy_count is 0 or 1 (rarely >1)
- Factor = noisy_count/lam = 0 or 1/lam (e.g., 52x at lam=0.019)
- This HUGE multiplicative noise creates the LER signal
- As dose increases, lam increases, 1/lam DECREASES
- But acid itself INCREASES with dose (acid ∝ dose)
- Result: noisy_acid noise ∝ acid/lam ∝ dose/(dose) = constant, NOT 1/√dose

The rescaling noisy_acid = acid × (noisy_count / lam) is FLAWED:
- It assumes acid ∝ lam, but acid ∝ dose while lam ∝ dose
- acid/lam = constant, so noise factor = noisy_count/lam ∝ 1/lam
- Poisson variance of noisy_count = lam
- Variance of noisy_acid = acid² × Var(noisy_count)/lam² = acid² × lam/lam² = acid²/lam
- Since acid ∝ dose and lam ∝ dose: variance ∝ dose²/dose = dose
- Standard deviation ∝ √dose → LER ∝ √dose (WRONG!)

CONFIDENCE: HIGH – MATHEMATICALLY PROVEN
PRIORITY: P0 – FUNDAMENTAL SHOT NOISE IMPLEMENTATION ERROR

RECOMMENDED FIX:
The rescaling logic should preserve Poisson statistics:
```python
# Correct approach: noisy_acid = acid + (noisy_count - lam) / (lam / acid)
# Or better: directly work in photon counts, not acid concentrations
# Mean photon count: N_ph = dose × area / E_ph
# Noisy photon count: N_ph_noisy ~ Poisson(N_ph)
# Noisy acid = N_ph_noisy × QE / (area / dx²)  [convert to concentration]
```
