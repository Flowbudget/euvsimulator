2. EXACT MATHEMATICAL ERROR(S)
====================================================================

  Bug 1 — Eigenvalue problem:
    Code:  A = Toeplitz(1/ε) - Kx @ inv(Toeplitz(1/ε)) @ Kx
    This gives q² = 1/ε₀ - ε₀·sin²θ for uniform medium at θ=0°.
    Correct: q² = ε₀ (normal incidence).

    For a uniform medium at normal incidence, q² should be ε₀.
    The code gives q² = 1/ε₀.

  Bug 2 — Modal admittance (V):
    Code:  V = W @ diag(q)  [same as TE]
    For TM, the correct modal admittance maps H_y (eigenmode) → E_x (continuous
    tangential field). The TE admittance maps E_y → H_x.
    TM requires V = Toeplitz(ε) @ W @ diag(1/q).

  Bug 3 — Interface matching:
    Because V is wrong, the S-matrix interface matching (A = V + Y_R @ W)
    is inconsistent for TM, producing incorrect reflection coefficients.

  Numerical evidence (100 nm Ta slab, normal incidence):
    TE R₀ = 0.001069 (matches TMM)
    TM (old) R₀ = 0.633242 (factor 600 error)
    TM (fixed) R₀ = 0.001069 (matches TMM)


3. CORRECT DERIVATION
====================================================================

  The TM wave equation for H_y in a 1D periodic medium (exp(iωt)):
    ∂²H_y/∂z² + k₀²·ε·H_y = ε·∂/∂x[1/ε·∂H_y/∂x]

  Fourier expansion H_y(x,z) = Σ U_m(z) · exp(-i·k_xm·x):
    ∂/∂x → -i·k₀·Kx  (diagonal)

  The RHS operator ε·∂/∂x[1/ε·∂/∂x] in Fourier space:
    Step 1: 1/ε·∂H_y/∂x → E_inv @ (-i·k₀·Kx·U)  [Laurent rule: ∂H_y/∂x is continuous]
    Step 2: ∂/∂x of that → -k₀²·Kx @ E_inv @ Kx @ U
    Step 3: ε·(result) → -k₀²·E_eps @ Kx @ inv(E_eps) @ Kx @ U  [Li's inverse rule:
             both ε(x) and the derivative result are discontinuous at same points]

  Full equation:
    d²U/dz² + k₀²·E_eps·U = -k₀²·E_eps @ Kx @ inv(E_eps) @ Kx @ U
    d²U/dz² + k₀²·(E_eps - E_eps @ Kx @ inv(E_eps) @ Kx) @ U = 0

  A_TM = E_eps - E_eps @ Kx @ inv(E_eps) @ Kx

  For the modal admittance V (H_y → E_x at interface):
    E_x = η₀ · (1/ε) · ∂H_y/∂z / (i·k₀) = η₀ · (1/ε) · (W @ diag(q) @ c)
    In Fourier, using Li's inverse rule:
    Ê_x = η₀ · inv(E_eps) @ W @ diag(q) @ c
    But the normalized admittance in the code is:
    V = E_eps @ W @ diag(1/q)
    This satisfies V = Y_R @ W for matched interfaces (uniform medium),
    where Y_R_TM = n²·k₀/kz = ε₀/q.

    Rayleigh admittance TM:  Y = n²·k₀/kz
    Interface S-matrix:  A = V + Y_R @ W,  B = Y_R @ W - V
    S[0,0] = 2W·A⁻¹·Y_R - I
    (unchanged architecture)


5. WHY THE OLD IMPLEMENTATION FAILED
====================================================================

  1. The old code built Toeplitz(1/ε) instead of Toeplitz(ε) for TM.
     For a uniform medium, Toeplitz(1/ε₀) = (1/ε₀)·I, giving q² = 1/ε₀
     instead of q² = ε₀.

  2. The old code used the identity V = W @ diag(q) for TM, which is the
     TE admittance formula. For TM, the correct admittance involves
     E_eps @ W @ diag(1/q), accounting for the ε(x) factor in the
     constitutive relation between E_x and ∂H_y/∂z.

  3. The old code used Kx @ inv(Toeplitz(1/ε)) @ Kx instead of
     E_eps @ Kx @ inv(E_eps) @ Kx in the eigenvalue problem. The
     factor E_eps comes from the ε(x) operator acting on the Fourier
     representation of ∂/∂x[1/ε·∂H_y/∂x].


6. WHY THE NEW IMPLEMENTATION IS CORRECT
====================================================================

  1. Homogeneous-medium limit: A_TM = ε₀I - Kx², giving q² = ε₀ - sin²θ,
     matching the correct dispersion relation for a plane wave.

  2. Normal-incidence degeneracy: TE = TM for all thicknesses and
     materials (verified: 0, 10, 50, 100 nm, n=0.94+0.03j).

  3. Fresnel bare interface: |r_TM| matches Fresnel r_p at 0°, 6°, 30°,
     45° (verified: diff < 1e-6).

  4. TMM slab comparison: TM R₀ matches TMM TM at 0°, 6°, 30° for
     absorbing slab (verified: rel diff < 5%).

  5. Physical reflectivity: R_m ≤ 1 for all orders (verified: uniform
     slab, binary grating, both TE and TM).

  6. S-matrix interface consistency: at matched interfaces (uniform
     material on both sides), V = Y_R @ W, giving zero reflection.

10. REMAINING RCWA LIMITATIONS
====================================================================

  1. TM convergence is slower than TE for binary gratings (H_y-based
     Fourier formulation). This is a known limitation addressed by
     Lalanne & Morris (1996) but requires additional matrix inversions.
     Current convergence tolerance: 0.01 between M=21 and M=31.

  2. diffraction_efficiency() method returns |R_m|² without kz-
     admittance weighting. This is NOT a true power efficiency for
     oblique incidence or evanescent orders. The method is only used
     in tests, not in the pipeline.

  3. Single permittivity profile for all RCWA layers (one Toeplitz
     matrix for all thickness entries). True alternating-material
     stacks require per-layer Toeplitz matrices.

  4. 2D RCWA is a scalar stub (no TE/TM cross-coupling).


11. POLARIZATION AVERAGING — SEPARATE ISSUE
====================================================================

  The pipeline polarization averaging (pipeline.py line 676):
    reflected_orders = (orders_te + orders_tm) / 2.0

  This was NOT fixed in this phase. It remains a separate issue:

  After the TM solver fix, both TE and TM produce physically correct
  complex amplitudes. However, the pipeline averages them as complex
  fields, which is a COHERENT superposition. For unpolarized
  (incoherent) illumination, the correct approach is to average the
  AERIAL IMAGES (intensities), not the field amplitudes.

  The correct fix (separate change):
    aerial_te = aerial_from_orders(orders_te, ...)
    aerial_tm = aerial_from_orders(orders_tm, ...)
    aerial = (aerial_te + aerial_tm) / 2.0

  This should be implemented as a separate, validated change after
  the TM solver fix is confirmed stable.

  Note: the thin-mask path (TMM-based, TE-only) is unaffected by
  both the TM fix and the polarization averaging issue.
