2. IMPLEMENTIERTE FUNKTION
============================================================

photon_deposition_shot_noise(
    dose: torch.Tensor,          # [mJ/cm2] deterministische Dosis
    se_blur_nm: float,           # SE-PSF sigma [nm]
    dx_nm: float = 1.0,          # Gridabstand [nm]
    dy_nm: float | None = None,  # optional (default = dx_nm)
    photon_energy_eV: float = 91.84014696703977,
    dose_to_energy_factor: float = 6.241509074e15,
    absorption: float = 1.0,     # eta_abs, optional
    seed: int | None = None,     # Reproduzierbarkeit
    rng: torch.Generator | None = None,  # expliziter RNG (Vorrang vor seed)
) -> torch.Tensor               # D_eff [mJ/cm2]

ABLAUF (exakt nach Audit-Abschnitt 5):
  1. A_voxel_cm2 = dx_nm * dy_nm * 1e-14
  2. N_bar = dose * A_voxel_cm2 * dose_to_energy_factor / photon_energy_eV
            * absorption
     N_bar = clamp(N_bar, min=0)   [physikalisch: keine negativen Zaehler]
  3. N ~ Poisson(N_bar)            [diskrete Photonenereignisse]
  4. E_dep = gaussian_se_blur(N, sigma=se_blur_nm, dx=dx_nm)
     E_bar = gaussian_se_blur(N_bar, sigma=se_blur_nm, dx=dx_nm)
     (bei se_blur_nm <= 0: E_dep = N, E_bar = N_bar — Identitaet)
  5. D_eff = dose * E_dep / E_bar.clamp(min=1e-30)   [nur numerischer Schutz]
  6. Rueckgabe: D_eff

EIGENSCHAFTEN (durch Tests verifiziert):
  - E[D_eff] = dose (erwartungstreu, globaler Bias < 1%)
  - räumliche Korrelation ueber die SE-PSF (Lag-1 > 0.5 bei blur=5)
  - Grid-Invarianz der relativen Rauschamplitude (< 20% ueber 3 Grids)
  - seed -> reproduzierbar; rng hat Vorrang vor seed
  - se_blur_nm <= 0 -> sauberes Weissrauschen (Identitaets-PSF)
  - dose = 0 -> keine NaNs/Infs, Ergebnis 0
  - keine kuenstlichen Grenzen (keine Clamps auf Dosis/QE/LER;
    nur clamp(min=1e-30) gegen Division durch Null)

4. ANALYSE DER ZUERST FEHLGESCHLAGENEN TESTS
============================================================

Beim ersten Lauf schlugen 4 Tests fehl (alle im se_blur=0-Pfad).
Ursache: FEHLER IN DEN TESTS, NICHT IN DER FUNKTION.

  a) TestPoissonMoments: Die Hilfsfunktion photon_moments_from_d_eff
     gab Var[N] zurueck (rel.var() * n_bar^2), der Test verglich aber
     mit 1.0 (Var[N]/N_bar). Korrektur: Faktor n_bar statt n_bar^2.
     Nach Korrektur: E[N]/N_bar = 1.0004, Var[N]/N_bar = 1.0018
     (Poisson-Momente exakt bestaetigt).

  b) TestUnbiasedness[0.0]: Bei se_blur=0 und dx=0.25 nm ist
     N_bar = 0.85 Photonen/Voxel -> per-Pixel-Varianz riesig;
     60 Realisierungen erreichen keine 2%-Schwelle pro Pixel.
     Korrektur: Globaler Mittelwert ueber alle Pixel & Realisierungen
     (statistisch solide). Globaler Bias < 1% fuer alle se_blur-Werte.

  Diese Korrekturen betreffen NUR die neuen Tests, nicht die Funktion.
