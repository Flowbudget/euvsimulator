2. MAXWELL DERIVATION
====================================================================

  Starting from Maxwell's equations with exp(iωt):

  TM: H = (0, H_y, 0), E = (E_x, 0, E_z)

  Wave equation (derived from ∇×H = iωε₀εE, ∇×E = -iωμ₀H):
    (1/ε)·∂²H_y/∂z² + ∂/∂x((1/ε)·∂H_y/∂x) = k₀²·H_y

  Multiplying by ε:
    ∂²H_y/∂z² + ε·∂/∂x((1/ε)·∂H_y/∂x) = k₀²·ε·H_y

  Fourier expansion H_y = Σ U_m(z)·exp(-i·k_xm·x):
    d²U/dz² + FT[ε·∂/∂x·(1/ε)·∂H_y/∂x] = k₀²·E_eps·U

  The operator ε·∂/∂x·(1/ε)·∂/∂x in Fourier space involves two nested
  products that both have concurrent discontinuities at material boundaries.
  Li's inverse rule is required for both products.

  The mathematically derived Fourier operator (using Li's inverse rule):
    FT[ε·∂/∂x·(1/ε)·∂H_y/∂x] = -k₀²·inv(Toeplitz(1/ε))·Kx·inv(Toeplitz(ε))·Kx·U
                              = -k₀²·inv(E_inv)·Kx·inv(E_eps)·Kx·U

  This gives the eigenvalue problem:
    A_TM = -inv(E_inv)·(I + Kx·inv(E_eps)·Kx)

  For a uniform medium: inv(E_inv) = ε₀·I, inv(E_eps) = (1/ε₀)·I
    A = -ε₀·I - ε₀·Kx·(1/ε₀)·Kx = -ε₀·I - Kx²
    q² = -ε₀ - sin²θ

  This has the wrong sign (should be +ε₀ - sin²θ), indicating a sign
  convention issue in the derivation, likely related to the time/space
  dependence convention in the Fourier expansion. The sign of the E_eps
  term depends on the assumed Fourier expansion direction (exp(-i·k_xm·x)
  vs exp(+i·k_xm·x)) and the time dependence (exp(iωt) vs exp(-iωt)).

  This is a well-known subtlety in RCWA formulations. The correct sign
  is determined empirically by matching the TE formulation (which is
  known to be correct) and achieving the correct uniform-medium limit.


3. FOURIER-FACTORIZATION CONCLUSION
====================================================================

  The current implementation uses:
    A_TM = E_eps - E_eps @ Kx @ inv(E_eps) @ Kx

  The mathematically derived form (Li inverse rule) gives:
    A_TM = -inv(E_inv) - inv(E_inv) @ Kx @ inv(E_eps) @ Kx
  (with sign issues noted above)

  Key finding: For a binary grating with ε₁=2.13, ε₂=1.0:
    max|inv(E_inv) - E_eps| = 0.108  (NOT negligible)

  The two formulations are NOT equivalent for discontinuous media:
    Current:  A = E_eps - E_eps·Kx·inv(E_eps)·Kx
    Li-rule:  A = inv(E_inv) - inv(E_inv)·Kx·inv(E_eps)·Kx

  (Note: the sign of the leading term depends on the convention, but the
  operator structure differs fundamentally.)

  For a UNIFORM medium, inv(E_inv) = E_eps = ε₀·I, so both formulations
  are identical. The existing homogeneous-medium tests CANNOT distinguish
  between them.

  This is a well-known ambiguity in the RCWA literature:
  - Moharam et al. (1995) used the Laurent-Laurent formulation
  - Li (1996) showed that the inverse rule is required for TM
  - Lalanne & Morris (1996) proposed the E_eps - Kx·inv(E_inv)·Kx form
    but this gives the wrong uniform-medium dispersion for oblique incidence
    under the normalization used by this code

  The current implementation's choice (E_eps as the outer factor) is
  supported by the empirical evidence (correct uniform-medium dispersion,
  TMM matching) but the Li-correct form (inv(E_inv) as the outer factor)
  has not been tested against an independent reference for periodic media.

  THEREFORE: The Fourier factorization is EMPIRICALLY PLAUSIBLE but
  not rigorously proven for discontinuous periodic media.


4. MODAL-ADMITTANCE CONCLUSION
====================================================================

  The current implementation uses:
    V_TM = E_eps @ W @ diag(1/q)

  This is verified to be correct:
  1. For a uniform medium: V = ε₀·W·(1/q) = n²·W·(1/q) = n²/q
     The Rayleigh admittance for TM is Y_TM = n²·k₀/kz = n²/q
     At a matched interface: V = Y_R·W → n²/q·W = n²·W·(1/q) ✓

  2. The interface continuity equation uses A = V + Y_R@W, which is
     the correct condition for tangential E_x continuity.

  3. The old code used V = W@diag(q) (TE-like), which gives V = n·W for
     a uniform medium, giving the wrong admittance for TM.

  The modal admittance fix is MATHEMATICALLY CORRECT.

7. POWER-NORMALIZATION CONCLUSION
====================================================================

  The diffraction_efficiency() method returns |R_m|² without kz-admittance
  weighting. This is NOT the true power efficiency for oblique incidence,
  but it is consistent with the field-amplitude normalization used by the
  solver.

  The power normalization comment in the existing test (test_lossless_tm)
  is accurate: "The scalar TM diffraction_efficiency does not weight orders
  by the kz-admittance ratio, so the raw efficiency *sum* can exceed 1.0."

  The |R_m|² ≤ 1 test (test_tm_physical_reflectivity) is valid for a passive
  structure because the reflection coefficient amplitude is bounded by the
  incident amplitude. However, it is a NECESSARY condition, not a sufficient
  test of the solver.

  Power normalization is a separate issue from the TM eigenproblem and
  should not be changed during this review.

9. EXACT REMAINING RISKS
====================================================================

  Risk 1 — Fourier factorization for periodic media (P1):
    The current implementation uses E_eps = Toeplitz(eps) as the outer
    factor in the TM operator. The mathematically correct Li inverse rule
    gives inv(Toeplitz(1/eps)) = inv(E_inv). These differ by up to 10%
    for binary gratings. The correct choice depends on the sign and
    Fourier convention, which has not been rigorously verified.

  Risk 2 — Slow TM convergence (P2):
    TM R₀ for a binary grating has not converged at M=151 orders.
    This is a known limitation of the H_y-based formulation, but it
    means that all practical TM RCWA simulations have residual
    convergence error.

  Risk 3 — No independent periodic-medium reference (P2):
    No published benchmark, independent implementation, or analytical
    result was used to validate the TM formulation for discontinuous
    periodic media. All validation is limited to homogeneous media.

  Risk 4 — Pipeline polarization averaging (P1):
    The pipeline still averages complex fields instead of intensities.
    This is a separate bug that was NOT fixed in this phase.

  Risk 5 — diffraction_efficiency() kz weighting (P3):
    The diagnostic method returns |R_m|² without kz weighting.
    Only affects tests, not the pipeline.


10. FINAL VERDICT
====================================================================

  VERDICT: B — EMPIRICALLY PLAUSIBLE BUT NOT SUFFICIENTLY VALIDATED

  The current implementation is:
  - MATHEMATICALLY CORRECT for homogeneous media ✓
  - MATHEMATICALLY CORRECT for the modal admittance ✓
  - EMPIRICALLY PLAUSIBLE for periodic media (passes all physical
    constraints: TE=TM degeneracy, |R_m| ≤ 1, symmetry)
  - NOT RIGOROUSLY VALIDATED for discontinuous periodic media
    (the Fourier factorization of the outer ε operator has an
    unresolved ambiguity, and no independent reference is available)

  The implementation is a significant improvement over the old code.
  The two bugs that were fixed (wrong eigenvalue problem, wrong modal
  admittance) are unquestionably correct. The remaining ambiguity is
  in the factor between E_eps and inv(E_inv) in the operator, which
  only matters for discontinuous media.

  The old code failed all homogeneous-medium tests (TE≠TM, |R|²>1,
  TMM mismatch). The new code passes all homogeneous-medium tests.
  The ambiguous Fourier factorization only affects the convergence rate
  for periodic media, not the correctness of the homogeneous limit.

  Recommended action: Add a published RCWA benchmark (e.g., from
  Moharam & Gaylord 1995, Tables 1-4) to validate the TM formulation
  for a lossless binary grating. The exact published values would
  resolve the Fourier factorization ambiguity.

  Do NOT commit the current changes until at least one of:
  a) A published benchmark confirms the TM results, OR
  b) The convergence with M → ∞ is demonstrated for the benchmark, OR
  c) An independent RCWA implementation validates the results.
