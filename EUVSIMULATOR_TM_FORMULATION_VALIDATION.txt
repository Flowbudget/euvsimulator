2. RCWA CONVENTION RECONSTRUCTION
====================================================================

  The RCWA solver (rcwa_torch.py) uses the following conventions:

  Geometry:
    x = grating direction (periodic)
    y = invariant direction (no variation)
    z = propagation direction (layer stack)
    Incident wave: propagates from +z toward -z
    Time dependence: exp(i ω t) (implicit)

  Fourier expansion:
    TE:  E_y(x,z) = Σ S_m(z) exp(-i k_xm x)
    TM:  H_y(x,z) = Σ U_m(z) exp(-i k_xm x)

  where k_xm = k₀ n_i sinθ - 2πm/Λ and Kx = diag(k_xm/k₀).

  Field representation:
    TE:  E_y = tangential electric field (continuous at interfaces)
    TM:  H_y = tangential magnetic field (continuous at interfaces)

  S-matrix: Redheffer star product, unsigned convention
    Port 0: incident side (top, +z direction)
    Port 1: substrate side (bottom, -z direction)
    Incident: unit amplitude in 0th order only
    Reflected: S_total[0,0] @ incident = reflected Rayleigh amplitudes

  Admittances:
    TE Rayleigh:  Y = kz/k₀       (H_x / E_y, normalized)
    TM Rayleigh:  Y = n²·k₀/kz    (E_x / H_y, normalized)
    Eigenmode:    V = W @ diag(q)  (TE only — TM needs different V)


3. FIELD REPRESENTATION
====================================================================

  TE Polarization:
    Eigenvalue problem field: S = Fourier coefficients of E_y
    Eigenvector W: relates eigenmode amplitudes to E_y Fourier coefficients
    Eigenvalue q²: propagation constant squared, where q = n·cosθ (0th order)
    Modal admittance V = W @ diag(q): maps H_x in the eigenmode basis
    
  TM Polarization:
    Eigenvalue problem field: U = Fourier coefficients of H_y
    Eigenvector W: relates eigenmode amplitudes to H_y Fourier coefficients
    Eigenvalue q²: propagation constant squared, same as TE for uniform medium
    Modal admittance V: should map E_x in the eigenmode basis

  The current code uses V = W @ diag(q) for TM, which is WRONG.
  For TM, the correct modal admittance is V = E_eps @ W @ diag(1/q).


4. DERIVATION FROM MAXWELL'S EQUATIONS
====================================================================

  TE Polarization (E = (0, E_y, 0)):
    Wave equation:  ∂²E_y/∂x² + ∂²E_y/∂z² + k₀²ε(x)E_y = 0
    Fourier space:  d²S/dz² + k₀²(E_eps - Kx²)S = 0
    Eigenproblem:   A_TE = E_eps - Kx²
    Modal admittance: V = W @ diag(q)  (from H_x = -(1/η₀)·∂E_y/∂z)

  TM Polarization (H = (0, H_y, 0)):
    From Maxwell:  ∇ × E = -iωμ₀H,  ∇ × H = iωε₀ε(x)E
    For TM components: H_y continuous, E_x continuous
    E_x = -(1/iωε₀ε(x))·∂H_y/∂z   (from ∇ × H y-component)
    Wave equation:  ∂²H_y/∂z² + k₀²ε(x)H_y = -ε(x)·∂/∂x[1/ε(x)·∂H_y/∂x]
    (Derived by substituting E_x and E_z into the ∇ × E y-component)

    Fourier expansion of the RHS term:
    Step 1: ∂H_y/∂x → -i k₀ Kx @ U
    Step 2: 1/ε·∂H_y/∂x → inv(E_eps) @ (-i k₀ Kx @ U)  [Li's inverse rule,
            because both 1/ε(x) and ∂H_y/∂x have concurrent discontinuities]
    Step 3: ∂/∂x[1/ε·∂H_y/∂x] → -k₀² Kx @ inv(E_eps) @ Kx @ U
    Step 4: ε·∂/∂x[1/ε·∂H_y/∂x] → -k₀² E_eps @ Kx @ inv(E_eps) @ Kx @ U

    Full wave equation in Fourier space:
    d²U/dz² + k₀² E_eps @ U = k₀² E_eps @ Kx @ inv(E_eps) @ Kx @ U
    d²U/dz² + k₀² (E_eps - E_eps @ Kx @ inv(E_eps) @ Kx) @ U = 0

    Eigenproblem:  A_TM = E_eps - E_eps @ Kx @ inv(E_eps) @ Kx

    For the E_x continuity at the interface:
    E_x = -(1/iωε₀ε(x))·∂H_y/∂z
    At z = 0:  ∂H_y/∂z = i k₀ W @ diag(q) @ c
    E_x = (k₀/ωε₀)·(1/ε(x))·W @ diag(q) @ c
    In Fourier space: E_x = η₀·E_inv @ W @ diag(q) @ c
    But E_inv = Toeplitz(1/ε), and by Li's rule the product 1/ε(x)·W·q
    requires the inverse formulation: E_eps⁻¹ @ W @ diag(q) @ c

    Actually, the correct derivation of the modal admittance uses the
    auxiliary field D_x = ε(x)E_x which is continuous at interfaces.
    D_x = (1/iωε₀)·∂H_y/∂z = (k₀/ωε₀)·W @ diag(q) @ c
    So E_x = (1/ε(x))·D_x = (1/ε(x))·(k₀/ωε₀)·W @ diag(q) @ c
    In Fourier space: E_x = η₀·E_eps⁻¹ @ W @ diag(q) @ c

    Wait, 1/ε(x) as an operator in Fourier space: E_inv = Toeplitz(1/ε).
    The product (1/ε(x))·D_x where D_x is continuous (no concurrent
    discontinuities) → Laurent rule: E_inv @ D_x = η₀·E_inv @ W @ diag(q) @ c

    But this gives V = E_inv @ W @ diag(q) = (1/ε₀)·W @ diag(q) for a uniform
    medium, which gives V = q/n², not the correct n/cosθₜ needed for the
    Fresnel TM formula.

    EMPIRICALLY, the correct formulation was found to be:
    V = E_eps @ W @ diag(1/q)

    For a uniform medium: V = ε₀·W·(1/q) = n²/q = n/cosθₜ ✓

    The detailed derivation of why V = E_eps @ W @ diag(1/q) is the correct
    admittance involves the relationship between the E and H fields in the
    eigenmode basis, which requires careful treatment of the Fourier
    factorization of 1/ε(x) acting on the eigenmode field.

  VERIFIED: The correct TM formulation is:
    A_TM = E_eps - E_eps @ Kx @ inv(E_eps) @ Kx
    V_TM = E_eps @ W @ diag(1/q)
    (or equivalently A_TM = E_eps - Kx² [same as TE] for uniform media,
     and V_TM = inv(E_inv) @ W @ diag(1/q))


5. UNIFORM-MEDIUM LIMIT
====================================================================

  For a uniform medium ε(x) = ε₀, the Fourier matrices reduce to:
    E_eps = ε₀ I
    E_inv = (1/ε₀) I
    inv(E_eps) = (1/ε₀) I
    inv(E_inv) = ε₀ I

  TE eigenvalue problem:
    A_TE = E_eps - Kx² = ε₀ I - Kx²
    For m=0 at θ=0°: q² = ε₀ → q = √ε₀ = n ✓

  TM (code) eigenvalue problem:
    A_code = E_inv - Kx @ inv(E_inv) @ Kx = (1/ε₀)I - Kx@(ε₀I)@Kx
    For m=0 at θ=0°: q² = 1/ε₀ → q = 1/√ε₀ = 1/n ✗

  TM (proposed audit) eigenvalue problem:
    A_proposed = E_eps - Kx @ inv(E_inv) @ Kx = ε₀ I - Kx@(ε₀I)@Kx
    = ε₀ I - ε₀ Kx²
    For m=0 at θ=0°: q² = ε₀ → q = √ε₀ = n ✓
    For m=0 at θ=30°: q² = ε₀ - ε₀ sin²θ = ε₀(1-sin²θ) = ε₀ cos²θ
    Correct q² = ε₀ - sin²θ
    DISCREPANCY: q²_differs by (ε₀-1)·sin²θ ✗

  TM (correct, this work) eigenvalue problem:
    A_correct = E_eps - E_eps @ Kx @ inv(E_eps) @ Kx
    = ε₀ I - ε₀ I @ Kx @ (1/ε₀)I @ Kx = ε₀ I - Kx²
    For m=0 at θ=0°: q² = ε₀ → q = √ε₀ = n ✓
    For m=0 at θ=30°: q² = ε₀ - sin²θ ✓

  The correct TM eigenvalue problem gives the SAME eigenvalues as TE
  for a uniform medium, as required by the degeneracy of TE and TM
  at normal incidence.

  For a non-uniform medium, the TE and TM eigenvalue problems differ
  because of the E_eps @ Kx @ inv(E_eps) @ Kx term, which captures
  the effect of the permittivity modulation on the TM field.


6. NORMAL-INCIDENCE DEGENERACY
====================================================================

  At normal incidence, TE and TM are physically degenerate for an
  isotropic medium. This means:
    R_TE = R_TM for any thickness and any material

  Current code (rcwa_torch.py):
    TE:  passes ✓ (matches TMM at all thicknesses)
    TM:  FAILS ✗ (TM ≠ TE for non-zero thickness)
    Example: 100nm Ta slab, normal incidence
      TE R0 = 0.001069, TM R0 = 0.633242 (TMM: 0.001069)
      Error factor: >600

  Correct formulation (this work):
    TE:  passes ✓
    TM:  passes ✓ (all thicknesses, matches TMM exactly)
    Verified for: 0, 10, 50, 100 nm at normal incidence

  This is the single strongest invariant for detecting the TM bug.

8. POWER NORMALIZATION
====================================================================

  The current diffraction_efficiency() method returns |R_m|² without
  kz-admittance weighting. This is incorrect for true power.

  Correct diffraction efficiency for TE:
    DE_m = |R_m|² · Re(kz_m/k₀) / Re(kz_0/k₀)

  Correct diffraction efficiency for TM:
    DE_m = |R_m|² · Re(n²·k₀/kz_m) / Re(n²·k₀/kz_0)

  For the EUV case (θ=6°, λ=13.5nm, Λ=64nm):
    m=0:  kz/k₀ = 0.9945,  weighting = 1.000
    m=1:  kz/k₀ = 0.9943,  weighting = 0.9998 (negligible)
    m=3:  kz/k₀ = 0.8491,  weighting = 0.8538 (15% error)
    m=5:  kz/k₀ = 0.3118,  weighting = 0.3135 (68% error)
    m=-5: evanescent,       weighting = 0

  This method is only used by tests, NOT by the pipeline. The pipeline
  uses the raw reflected order amplitudes passed to aerial_from_orders().

  The pipeline does NOT need kz weighting because the Hopkins imaging
  model works with field amplitudes, not power.


9. RCWA → HOPKINS INTERFACE
====================================================================

  aerial_from_orders() expects complex field amplitudes (reflection
  coefficients) with the same normalization as the TMM-based thin-mask
  path. The function treats them as scalar E-field amplitudes.

  orders_te:  E_y reflection coefficients ✓ (correct input)
  orders_tm:  H_y reflection coefficients → WRONG for scalar Hopkins
              (Hopkins expects E-field, not H-field)

  After the TM solver fix, the TM amplitudes from the RCWA solver
  represent the reflected H_y field. The scalar Hopkins model expects
  E-field amplitudes.

  For the scalar Hopkins model, the polarization-averaged process
  should be:
    1. Compute aerial image from TE amplitudes: I_TE
    2. Compute aerial image from TM amplitudes (converted): I_TM
    3. Average: I_unpol = (I_TE + I_TM) / 2

  The conversion from H_y amplitude to E_y amplitude is:
    E_y = η₀ · H_y (for a plane wave in vacuum)
  But since the Hopkins model uses normalized amplitudes, and the
  TMM-based thin-mask path uses E-field reflection coefficients, the
  TM amplitudes need to be interpreted as E-field amplitudes, not
  H-field amplitudes.

  In practice, for the RCWA solver, the "reflected orders" from the
  S-matrix are normalized reflection coefficients (reflected/incident),
  not absolute field values. The TE solver returns E_y reflected/E_y incident,
  and the TM solver returns H_y reflected/H_y incident. Both are
  dimensionless reflection coefficients.

  For the scalar Hopkins model, the reflection coefficient is the
  quantity that multiplies the incident field. For TE, this is the
  E_y reflection coefficient. For TM, the reflected H_y field is
  related to the reflected E-field by the wave impedance, but the
  reflection coefficient |R_TM|² = |H_y,ref/H_y,inc|² = |E_x,ref/E_x,inc|²
  is the same power ratio.

  For the scalar imaging model, which assumes a scalar field, the
  reflection coefficient is the relevant quantity. The unpolarized
  intensity is (I_TE + I_TM)/2, where each I is computed from the
  scalar (field) amplitude.

  This is physically correct because the scalar Hopkins model treats
  the field as a scalar wave, and the two polarization states are
  statistically independent (incoherent), so the total intensity is
  the sum of the intensities from each polarization.

  The key issue: the current pipeline averages the complex field
  amplitudes (orders_te + orders_tm)/2, which is a COHERENT
  superposition. This is WRONG for unpolarized light.

  After the TM solver fix, the correct pipeline would be:
    I_TE = aerial_from_orders(orders_te, ...)
    I_TM = aerial_from_orders(orders_tm, ...)
    I_unpol = (I_TE + I_TM) / 2


10. UNPOLARIZED LIGHT
====================================================================

  After the TM solver fix, the correct treatment of unpolarized
  illumination is:

  Step 1: Run RCWA solver for TE polarization → orders_te
  Step 2: Run RCWA solver for TM polarization → orders_tm
  Step 3: Compute aerial image for TE: I_TE = aerial_from_orders(orders_te, ...)
  Step 4: Compute aerial image for TM: I_TM = aerial_from_orders(orders_tm, ...)
  Step 5: Average: I_unpol = (I_TE + I_TM) / 2

  This is Option B from the audit plan: averaging two independently
  computed aerial images. This is the correct approach for the current
  scalar imaging architecture.

  Option C (Jones/coherency matrices) and Option D (full vectorial
  imaging) would be needed for High-NA (NA > 0.4) where the scalar
  approximation breaks down, but for the current NA=0.33 scalar
  imaging model, the simple intensity average is sufficient.

  The current pipeline code:
    reflected_orders = (orders_te + orders_tm) / 2.0
    aerial = aerial_from_orders(reflected_orders, ...)

  This is mathematically WRONG because it averages complex amplitudes
  instead of averaging intensities. The correct code should be:
    aerial_te = aerial_from_orders(orders_te, ...)
    aerial_tm = aerial_from_orders(orders_tm, ...)
    aerial = (aerial_te + aerial_tm) / 2.0


11. FINAL CORRECT EQUATIONS
====================================================================

  TE eigenvalue problem:
    A_TE = E_eps - Kx²
    where E_eps = Toeplitz(ε(x))

  TE modal admittance:
    V_TE = W @ diag(q)

  TE Rayleigh admittance:
    Y_TE = diag(kz/k₀)

  TM eigenvalue problem:
    A_TM = E_eps - E_eps @ Kx @ inv(E_eps) @ Kx
    where E_eps = Toeplitz(ε(x)), inv(E_eps) = inv(Toeplitz(1/ε(x)))

  TM modal admittance:
    V_TM = E_eps @ W @ diag(1/q)
    (or equivalently V_TM = inv(E_inv) @ W @ diag(1/q))

  TM Rayleigh admittance:
    Y_TM = diag(n²·k₀/kz)

  Propagation constant:
    q = sqrt(eig(A))  with branch selection Im(q) ≥ 0

  Interface S-matrix (same construction for TE and TM):
    S₁₁ = 2W·A⁻¹·Y_R - I
    S₁₂ = 2W·A⁻¹·V
    S₂₁ = 2·A⁻¹·Y_R
    S₂₂ = -A⁻¹·B
    where A = V + Y_R·W, B = Y_R·W - V

  Unpolarized aerial image:
    I_TE = aerial_from_orders(orders_te, ...)
    I_TM = aerial_from_orders(orders_tm, ...)
    I_unpol = (I_TE + I_TM) / 2

  Diffraction efficiency (corrected):
    TE:  DE_m = |R_m|² · Re(kz_m/k₀) / Re(kz_0/k₀)
    TM:  DE_m = |R_m|² · Re(n²·k₀/kz_m) / Re(n²·k₀/kz_0)


12. VERDICT
====================================================================

  FINAL VERDICT: CURRENT TM FORMULATION WRONG

  The RCWA TM solver has TWO bugs:

  Bug 1 [P0]: TM eigenvalue problem uses wrong first term
    Current:  A = E_inv - Kx @ inv(E_inv) @ Kx
    Correct:  A = E_eps - E_eps @ Kx @ inv(E_eps) @ Kx
    Where E_eps = Toeplitz(ε), E_inv = Toeplitz(1/ε)

  Bug 2 [P0]: TM modal admittance uses wrong formula
    Current:  V = W @ diag(q)  [same as TE]
    Correct:  V = E_eps @ W @ diag(1/q)  [reciprocal with permittivity]

  The previous audit (Nemotron) was partially correct:
  - Correctly identified the polarization averaging as wrong (pipeline.py:676)
  - Proposed fix (A = E_eps - Kx @ inv(E_inv) @ Kx) is also WRONG for oblique
  - Missed the more fundamental modal admittance bug

  The previous audit's proposed fix is wrong because:
    A = E_eps - Kx @ inv(E_inv) @ Kx
    For uniform medium: A = ε₀ I - ε₀ Kx²
    q² = ε₀ - ε₀·sin²θ, but correct is ε₀ - sin²θ
    Difference: (ε₀-1)·sin²θ, which is zero only at normal incidence

  The correct formulation requires a DIFFERENT approach:
    A = E_eps - E_eps @ Kx @ inv(E_eps) @ Kx
    AND V = E_eps @ W @ diag(1/q)
