Step 4
Topic: Photon Shot Noise / Dose Coupling

1. CURRENT PHOTON COUNT PATH

Before this fix, the photon shot noise was not properly coupled to the physical dose:

SimulationConfig.dose_mj_cm2
    -> aerial image (scaled by dose)
    -> dose_map (local dose [mJ/cm²])
    -> dose_to_acid() -> acid
    -> PEB -> inhib
    -> deprotected = 1 - inhib
    -> ler_lwr_estimate(acid=deprotected, dose=None)  # PROBLEM: dose=None!
        -> poisson_shot_noise(acid, dose=None)
            -> fallback: lam = acid * 100 (heuristic, no physical dose scaling)

The dose map was available but not passed to the shot noise function. The function fell back to a heuristic lam = acid * 100, which had no physical relationship to photon count.

4. UNIT ANALYSIS

Photon energy: E_photon [J] = E_eV * e = E_eV * 1.602176634e-19 J/eV

Dose: D [mJ/cm²] = D * 1e-3 J/cm²

Energy per cm²: E_cm2 = D * 1e-3 [J/cm²]

Photons per cm²: N_cm2 = E_cm2 / E_photon = D * 1e-3 / (E_eV * 1.602176634e-19)
                   = D * 6.241509074e15 / E_eV

Pixel area: A_px = dx_nm * dy_nm * 1e-14 [cm²]

Photons per pixel: N_px = N_cm2 * A_px = D * 6.241509074e15 / E_eV * dx_nm * dy_nm * 1e-14

Mean acid count per pixel: λ_acid = N_px * QE = D * dx * dy * 1e-14 * 6.241509074e15 * QE / E_eV

Deterministic acid concentration: acid = Q * (1 - exp(-C * D_blurred))
This acid is proportional to D_blurred, which is proportional to photon flux.

The rescaling: noisy_acid = acid * (noisy_count / λ_acid)
Ensures E[noisy_acid] = acid and Var[noisy_acid] = acid² / λ_acid

5. PIXEL AREA CALCULATION

dx_nm = period_nm / grid  [nm/pixel]
dy_nm = dx_nm  (square pixels)

voxel_area_cm2 = dx_nm * dy_nm * 1e-14

Example: period=64 nm, grid=256
dx_nm = 64/256 = 0.25 nm
voxel_area_cm2 = 0.25 * 0.25 * 1e-14 = 6.25e-16 cm²

6. PHOTON COUNT FORMULA

photons_per_voxel = dose * voxel_area_cm2 * dose_to_energy_factor / photon_energy_eV
where:
- dose: [mJ/cm²]
- voxel_area_cm2: [cm²]
- dose_to_energy_factor = 6.241509074e15 [eV/(mJ/cm²)]
- photon_energy_eV: [eV]

mean_acid_count = photons_per_voxel * quantum_efficiency

7. DOSE COUPLING

The pipeline now passes the dose_map_blurred (local dose after SE blur) to the stochastic LER/LWR estimation:

dose_map_blurred = gaussian_se_blur(aerial * cfg.dose_mj_cm2, sigma=cfg.se_blur_nm, dx=dx_nm)

This dose map is passed to ler_lwr_estimate which passes it to poisson_shot_noise.
The shot noise function computes photons_per_voxel from this dose map.

12. PHYSICS JUSTIFICATION

Photon shot noise is a fundamental quantum effect. The number of absorbed EUV photons per pixel follows Poisson statistics with mean proportional to the local dose. The acid generation is proportional to the number of absorbed photons (via quantum efficiency QE).

Previous implementation:
- Used heuristic lam = acid * 100
- No physical dose coupling
- Pixel area hardcoded to 1 nm²
- Conversion factor approximate (6.24e15)

New implementation:
- Photon count computed from physical dose, pixel area, photon energy
- Exact conversion factor (6.241509074e15 eV per mJ/cm²)
- Pixel area computed from simulation grid (dx_nm, dy_nm)
- Acid concentration is the mean of the Poisson process
- Rescaling preserves deterministic acid as expectation value
- Variance scales as 1/mean (Poisson property)

This ensures:
1. Shot noise magnitude correctly reflects photon statistics
2. Dose dependence: N_ph ∝ dose -> σ/μ ∝ 1/√dose
3. Wavelength dependence: N_ph ∝ 1/E_ph
4. Pixel size dependence: N_ph ∝ dx*dy
5. Deterministic limit: as dose→∞, noise→0

13. REMAINING ISSUES

- RMS scaling test fixture (line_acid) has low peak values (0.5), leading to low photon counts at moderate doses. Tests pass but with generous tolerances. Fixture should be improved with higher peak acid for proper RMS scaling verification.

- ler_lwr_estimate uses acid as base for shot noise, but the physical process is photon absorption -> acid generation. Using acid is acceptable since acid ∝ dose (in linear regime), but a more physical model would apply shot noise to the dose map directly and then compute acid.

- The stochastic pathway applies shot noise to the final acid/deprotected map. A more rigorous model would apply shot noise earlier in the chain (dose -> absorption -> acid -> PEB -> development) with noise propagation through each step.

- n_realisations default is 1, which gives poor LER/LWR statistics. Should be increased for production use.
