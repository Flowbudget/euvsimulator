EUVSIMULATOR FIX REPORT
Coherence Cutoff Removal — Aerial Image Spatial Structure Restoration

1. SUMMARY

Fixed the critical bug where aerial images lost all spatial structure for certain parameter combinations (pitch=48 nm, NA=0.33, sigma=0.8). The bug was caused by a hard coherence cutoff that contradicted the physical TCC (2*J1/x) formula.

2. ROOT CAUSE

File: src/euvsimulator/aerial/abbe.py
Function: aerial_from_orders
Lines: 198-201 (removed)

Problem code (REMOVED):
    dm = abs(mi - mj)
    if dm > coherence_orders + 1e-12:
        continue  # outside coherence area

This hard cutoff blocked order interference (dm=1) when coherence_orders < 1, even though the physical TCC formula gives finite, non-zero values.

For pitch=48 nm, NA=0.33, sigma=0.8:
- coherence_orders = 0.8 * 0.33 * 48 / 13.5 = 0.9387
- dm(0,±1) = 1 > 0.9387 → BLOCKED
- TCC at dm=1: 2*J1(2.33)/2.33 ≈ 0.31 (NOT zero!)

3. FIX APPLIED

Removed the hard coherence cutoff (lines 198-201). The TCC formula naturally handles coherence filtering with gradual damping.

Pupil filter (max_order) retained — physically correct for orders outside the numerical aperture.

Reference test (test_reference_nils.py) updated to match: removed identical hard cutoff from reference model.

9. PHYSICS JUSTIFICATION

The Hopkins TCC for a circular source is μ = 2*J1(x)/x where x = π·σ·NA·dm·λ/Λ.
This function:
- μ(0) = 1
- Decays gradually with oscillations
- Asymptotically ~1/x^1.5
- NEVER reaches exactly zero

A hard cutoff at coherence_orders = σ·NA·Λ/λ is physically incorrect. It was a computational optimization that broke physics at low coherence_orders.

The TCC naturally suppresses high-dm interference. No artificial cutoff needed.
