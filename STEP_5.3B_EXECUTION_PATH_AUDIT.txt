============================================================
dose_mj_cm2 (Config; behandelt als ABSORBIERTE Dosis, da

aerial (λ, NA, σ, Illumination, ML, Maske) → dose_map
   │

   │    gaussian_se_blur(dose_map, se_blur_nm)          ← Blur auf Dosis
   │    → dose_to_acid(C=cfg.dill_C, Q=cfg.dill_Q, apply_blur=False)
   │    → reaction_diffusion_analytical(k, t_bake, sigma_diff; D NIE)
   │    → threshold_development(inhib, M_th)
   │    → CD, NILS
   │
   └── STOCHASTISCHER PFAD (LER/LWR):
        stoch_dose = tile/repeat(dose_map) [:grid_y]  (large_n)
        photon_deposition_shot_noise(stoch_dose, se_blur_nm,
          photon_energy_eV, f=6.2415e15 HARDCODED, absorption=1.0
          HARDCODED)
          → Poisson(n_bar = dose·A_voxel·f/E_ph·1.0)
          → gaussian_se_blur(Ereignisse, se_blur)      ← Blur auf EVENTS
        → dose_to_acid(C, Q, apply_blur=False) → acid_noisy
        → stochastic_development(acid_noisy, 0.3, strength, corr)
          ODER Threshold 0.3
        → extract_edges(interp. auf acid_noisy)
        → ler_estimate / extract_ler / extract_lwr → LER/LWR

INKONSISTENZ (AMBIGUOUS): Der SE-Blur wirkt im deterministischen
Pfad auf die Dosiskarte, im stochastischen Pfad auf die
Poisson-Ereignisse. Wegen der Nichtlinearität acid = Q·(1-exp(-C·D))
sind die effektiven Profile NICHT äquivalent (Jensen-Ungleichung:
exp(blur(x)) ≠ blur(exp(x))). Der Kommentar in pipeline.py
(Z.338-340) dokumentiert nur "kein zweiter Blur" — die
KONSISTENZ der beiden Anwendungen wurde nie geprüft. Konsequenz:
Die CD-Physik (det. Pfad) und die LER-Kantenlage (stoch. Pfad)
können systematisch abweichen. Physikalisch korrekt ist die
stochastische Anwendung (Energie wird pro Ereignis deponiert);
der deterministische Pfad ist eine Näherung.
