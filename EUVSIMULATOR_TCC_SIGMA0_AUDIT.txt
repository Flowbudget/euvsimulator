SIGMA=0 BEHAVIOR
====================================================================

  ZeroDivisionError CRASH at line 210 of src/euvsimulator/aerial/abbe.py:

    tcc = 2.0 * _j1(x) / x

  For sigma=0 and dm > 0: x = 0, _j1(0) = 0, 0/0 → ZeroDivisionError.

  The code correctly handles dm=0 (hardcoded tcc=1.0 at line 207), but
  EVERY cross-order pair (dm>0) at sigma=0 triggers 0/0.

  The physically correct fully-coherent limit is:
    lim(x→0) 2·J₁(x)/x = 1   for ALL dm

  → At sigma=0 the TCC matrix must be ALL ONES (rank-1, fully coherent).


TCC PHYSICS
====================================================================

  The TCC formula (line 209) is correct:
    TCC = 2·J₁(x) / x,   x = π·σ·NA·dm·λ/Λ

  This matches the standard Hopkins degree of coherence for a circular
  source.  The large-sigma limit is physically correct: TCC decreases
  monotonically with sigma (for sigma ≤ ~0.9), and the first zero of
  J₁(x) (x ≈ 3.83) is well beyond all practical EUV parameters.

  At sigma=0.8 (default) and dm=1: x ≈ 0.233, TCC ≈ 0.993 (physically
  plausible — nearly coherent).

  No evidence of accidental inversion or wrong Gaussian/TCC interpretation.


NUMERICAL VALIDATION
====================================================================

  CONFIRMED SECOND BUG (P0): Aerial squaring at line 217-218.

  The code accumulates the full Hopkins double-sum:
    A(x) = Σ_i Σ_j  r_i · r_j* · TCC(i,j) · exp(i·2π·(m_i−m_j)·x/Λ)

  This sum is ALREADY the real, physically correct intensity (the
  Hermitian pair (i,j)+(j,i) cancels the imaginary part).  Then:

    aerial_1d = (aerial_1d * aerial_1d.conj()).real   # line 217-218

  squares it:  aerial = [true_I(x)]²  instead of  aerial = true_I(x).

  NUMERICAL PROOF (3 orders, sigma=1e-6, TCC≈1):
    True Hopkins I:  min=0.048,  max=0.173,  mean=0.106
    Code aerial:     min=0.0023, max=0.030,  mean=0.013
    Code ≈ I_true²:  max|diff| = 4.7e-09  ✓  CONFIRMED

  CONSEQUENCES:
    • NILS doubles: NILS[I²] = 2·NILS[I]  (all past NILS values ~8.5
      are actually ~4.25 in physically correct units)
    • Contrast and absolute intensity scale are wrong
    • ALL pipeline results that use aerial_from_orders are affected
      (both use_rcwa and thin-mask paths)
    • The polarization fix is compatible (averages aerials after
      reconstruction) but the aerials it averages are squared


SIGMA→0 CONTINUITY
====================================================================

  FAIL (due to squaring bug, not just sigma=0 crash).

  The code's aerial at sigma→0 (sigma=1e-12) gives max=0.030 vs the
  physically correct max=0.173.  This is a factor ~5.7× discrepancy
  because the squaring bug compounds with the coherent limit.

  Even at sigma=0.8 (default), the aerial is I_true², which means
  ALL published NILS values are ~2× too high.


LARGE-SIGMA BEHAVIOR
====================================================================

  PASS (TCC formula is correct for the given implementation).

  TCC(dm=1) decreases monotonically from 0.9999 (σ=0.1) to 0.254
  (σ=10), consistent with the Hopkins J₁ form.  The first zero of
  J₁(x) is at x≈3.83 which corresponds to σ≈13.1 for the 48nm pitch —
  well beyond any practical EUV setting.


POLARIZATION INTERACTION
====================================================================

  PASS (compatible).

  The recently committed fix (5452893) averages TE and TM aerials
  AFTER reconstruction.  This is physically correct for unpolarized
  illumination.  The fix applies to the squared aerial (current code)
  and would remain correct if the squaring were fixed (the averaging
  acts on intensities in both cases).


NORMALIZATION
====================================================================

  FAIL (due to squaring bug).

  The aerial intensity is the square of the physically correct Hopkins
  intensity.  This means:
    • Wrong absolute scale (units are I², not I)
    • Wrong contrast ratio
    • Wrong NILS (factor 2)
    • Wrong CD extraction (threshold on squared intensity differs
      from threshold on true intensity)

REQUIRED FIX
====================================================================

  BUG 1 — sigma=0 (line 209-210, aerial/abbe.py):

    Replace:
        x = math.pi * sigma * na * dm * wavelength_m / period_m
        tcc = 2.0 * _j1(x) / x
    with:
        if abs(x) < 1e-15:
            tcc = 1.0
        else:
            tcc = 2.0 * _j1(x) / x

  where x = π·σ·NA·dm·λ/Λ.

  BUG 2 — aerial squaring (line 217-218, aerial/abbe.py):

    The double-sum is already real (Hermitian).  Replace:
        aerial_1d = (aerial_1d * aerial_1d.conj()).real
    with:
        aerial_1d = aerial_1d.real

    This removes the spurious |.|² that squares the intensity.

  AFTER BOTH FIXES:
    • NILS values will halve (from ~8.5 to ~4.25)
    • Absolute intensity scale will be correct
    • The sigma=0 coherent limit will be exact
    • The reference model (test_reference_nils.py) must ALSO be updated
    • All golden values in tests must be re-measured
