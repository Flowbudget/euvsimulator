EUVSIMULATOR PHYSICS CHANGE
Step 5
Topic: CD extraction from developed resist instead of aerial image

1. SUMMARY

Fixed P0-005: In the full_chem resist path, the critical dimension (CD) was being extracted from the aerial image instead of the actual developed resist profile. The full_chem pipeline now correctly computes CD from the developed resist profile (dev_chem) produced by the threshold_development function.

2. PROBLEM FOUND

In src/euvsimulator/pipeline.py, function _cd_via_full_chem (lines 328-344):
- The code computed a binary development mask from the aerial image using a fixed threshold
- It ignored the dev_chem profile that was already computed from the full resist chemistry chain (dose → acid → PEB → threshold_development)
- The CD was extracted from this aerial-derived binary mask, not from the physical resist development

This meant the "full_chem" CD was identical to the "aerial_threshold" CD by construction, defeating the purpose of the full chemistry model.

BEFORE:

    cut = aerial[half, :]

    # dev_chem: 1 = developed/dissolved, 0 = undeveloped/remaining
    # Für positive-tone: CD = width of undeveloped region (value 0)

Key changes:
1. Uses dev_chem (result of threshold_development) instead of aerial image
2. dev_chem polarity: 1 = developed/dissolved, 0 = undeveloped/remaining (positive-tone)
3. CD = width of undeveloped region → target=0 in _find_runs_1d
4. dev_2d = dev_chem.clone() for visualization (was aerial-derived)

Changed the test expectation: aerial_threshold and full_chem now give DIFFERENT CDs (by design), both should be reasonable (positive, in range 10-50 nm for nominal 32 nm line). NILS should still be similar since both use the dose map.

5. PHYSICS JUSTIFICATION

In positive-tone EUV resist:
- Dose → acid generation (Dill ABC)
- PEB → acid diffusion → deprotection (inhibitor reduction)
- Development → regions where inhibitor ≤ M_th dissolve (developed = 1)
- Remaining resist (undeveloped = 0) defines the final CD

The aerial image represents the optical intensity distribution. The developed resist profile represents the physical structure after chemical processing. The CD must come from the latter.

Before: CD derived from aerial intensity threshold → ignores resist chemistry
After: CD derived from dev_chem → incorporates Dill C/Q, PEB k/t_bake/sigma_diff, Mack M_th

10. REMAINING ISSUES

- The extract_cd function in resist/develop.py and metro/cd.py use different approaches (simple runs vs sub-pixel interpolation). The pipeline uses the simple _find_runs_1d method which gives pixel-accurate CD. For higher accuracy, sub-pixel interpolation from metro/cd.py could be used.

- The current CD extraction uses a simple 1D line cut at the middle row. A 2D edge detection (extract_cd_2d) with averaging across rows would be more robust for rough edges.

- The Mack model parameters (R_max, R_min, n, M_th) are now properly used in threshold_development, but the surface_advancement_level_set (3D level-set development) is not yet integrated. This is P1-005 in the audit.

- At se_blur=10 nm, the full_chem CD becomes 0.0 (fully developed). This is physically correct for the given parameters but indicates the test case is at the edge of the process window.

- The aerial_threshold path still uses the aerial image for CD. This is by design (it's a simplified model). The full_chem path is now the physically correct one.
