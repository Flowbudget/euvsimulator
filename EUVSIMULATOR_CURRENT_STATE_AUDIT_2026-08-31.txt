2.1 AERIAL IMAGE / ABBE / HOPKINS / TCC
--------------------------------------------------------------------

File: src/euvsimulator/aerial/abbe.py (427 lines)
File: src/euvsimulator/aerial/hopkins.py (332 lines)

- aerial_from_orders(): Hopkins 1D formulation:
    I(x) = sum_i sum_j r_i * r_j* * TCC(i,j) * exp(i*2pi*(m_i-m_j)*x/Lambda)
- TCC = 2*J1(x)/x, x = pi*sigma*NA*dm*lambda/period
- J1 Bessel (not J0) - correct for rotationally symmetric source
- Hard coherence cutoff: REMOVED (was blocking dm=1 at sigma=0.8)
- Pupil filter (|m| <= max_order): retained - physically correct
- sigma=0 limit: TCC(dm=0)=1.0, TCC(dm>0)=NaN (division by zero in
  2*J1(x)/x with x=0) - handled by dm==0 special case returning 1.0
- SE blur: REMOVED from aerial_from_orders (was double-applied)
- Legacy abbe_image() by source-point summation: still present, NOT
  used in production path

TCC Grenzfall sigma=0:
  dm=0: TCC=1.0 (correct)
  dm>0: x=pi*0*NA*dm*lambda/period=0 -> 2*J1(0)/0 = 0/0 = NaN
  Der Code behandelt dm==0 separat -> TCC=1.0 fuer dm=0.
  Fuer dm>0 bei sigma=0 wird _j1(0)/0 -> NaN.
  In der Praxis werden bei sigma=0 nie dm>0 erreicht, weil die
  Kohaerenzlaenge unendlich ist (alle Ordnungen interferieren
  vollstaendig kohaerent). Der NaN ist numerisch korrekt, da der
  TCC-Ausdruck fuer sigma=0 und dm!=0 singulaer ist.
  PHYSIKALISCH: sigma=0 -> delta-Quelle -> TCC=1 fuer alle dm.
  Das ist der kohaerente Grenzfall. Der Code produziert hier NaN
  fuer dm>0, aber durch die dm==0-Abfrage wird das in der Praxis
  abgefangen.

Hopkins TCC (compute_tcc in hopkins.py):
  - Full 2D TCC matrix: TCC = P_s * diag(w) * P_s^H
  - SOCS decomposition via torch.linalg.eigh
  - compare_hopkins_abbe(): cross-validation function exists

2.3 MULTILAYER / TMM
--------------------------------------------------------------------

File: src/euvsimulator/optics/multilayer.py (316 lines)
File: src/euvsimulator/optics/tmm.py (424 lines)

- S-matrix (scattering matrix) / Redheffer star product formulation
- TE: eta = kz/k0, TM: eta = n^2*k0/kz
- Ne vot-Croce interface roughness: r' = r * exp(-2*kz_a*kz_b*sigma^2)
- mo_si_stack(): builder for 50-bilayer Mo/Si mirror with grading
- reflectivity(): returns R, r for wavelength/angle grid
- Default: 50 BL Mo/Si, d_Mo=2.8 nm, d_Si=4.1 nm, Ru cap 2.5 nm
- Peak reflectivity: ~64.7% (ideal), ~60.6% (sigma=0.5 nm roughness)
- Grading: linear + parabolic period grading supported
- Branch selection: Im(kz) >= 0 (decaying into absorbing medium)
- Interdiffusion correction: inserts thin MoSi2-like layers at interfaces

2.4 MASK MODEL / RCWA
--------------------------------------------------------------------

File: src/euvsimulator/mask3d/geometry.py (210 lines)
File: src/euvsimulator/mask3d/rcwa_torch.py (442 lines)
File: src/euvsimulator/mask3d/rcwa2d.py (stub)

- RCWA1D: Fourier Modal Method with S-matrix cascade
- Eigenvalue problem: A = E - Kx^2 (TE), A = E - Kx*E^-1*Kx (TM)
- Stable branch selection: Im(q) > 0 for evanescent; Re(q) > 0 for near-real
- Convergence driver: auto-increase Fourier orders until R0 stabilises
- binary_grating_profile(): rectangular grating permittivity
- geometry.py: MaskStack, standard_euv_mask(), build_permittivity_profile()
- RCWA2D: Scalar stub only -> NO vector TE/TM cross-coupling

CRITICAL RCWA ISSUES:

  a) TE/TM unpolarized averaging (P1-001):
     pipeline.py: reflected_orders = (orders_te + orders_tm) / 2.0
     This averages COMPLEX FIELDS, not INTENSITIES.
     Correct: I_unpol = (|E_TE|^2 + |E_TM|^2) / 2

  b) Single permittivity profile for all layers:
     RCWA1D uses ONE Toeplitz matrix for every layer in the thickness
     list. Real EUV mask has different profiles per layer (absorber,
     capping, Mo/Si multilayer). The build_permittivity_profile path
     handles this correctly but the pipeline RCWA path uses it.

  c) No 2D vector RCWA: TE/TM coupling (>1D features like contact
     holes) not modelled.

  d) No energy conservation test for TM (documented: scalar TM
     efficiency sum can exceed 1.0 because kz-admittance weighting
     is missing).

  e) No energy loss check for absorbing gratings:
     |R| + |T| < 1 with absorption should be verified.

  f) No quantitative R_max/Imax check for metallic absorbing materials
     at EUV (Ta, Ni) - R > 1 possible with poor convergence.

2.8 STOCHASTIC MODEL / SHOT NOISE / LER/LWR
--------------------------------------------------------------------

File: src/euvsimulator/resist/stochastic.py (1136 lines)

Event-based model (photon_deposition_shot_noise, production):
  1. N_bar = dose * voxel_area * f / E_ph
  2. N ~ Poisson(N_bar)
  3. E_dep = SE_PSF(N)
  4. D_eff = dose * E_dep / E_bar
  5. acid = Q * (1 - exp(-C * D_eff))

Verified properties:
  - Poisson ratios: 0.994-1.004 (theory=1.0)
  - Dose scaling: slope = -0.498 ± 0.001, CI contains -0.5, R2 = 0.999978
  - Grid invariance: ratio 0.9973-0.9978 (grid 128-1024)
  - Autocorrelation: Lag-1 = 0.9995 (with sigma=5 nm SE blur)
  - Seed reproducibility: bitwise exact
  - Spatial correlation: rho(256) ≈ 0 -> no artificial periodicity

LER/LWR:
  - Legacy (naive): RMS over N=256 rows -> N_eff≈4.2 -> ~23% low bias
  - Production (Large-N): 4096x256 field, N_eff≈59, convergence < 1%
  - Correlation-aware CI via moving-block bootstrap
  - Large-N reference: ~0.071 nm (this configuration, not validated vs experiment)
  - edge="both" is production observable (left+right pooled)
  - Disclaimer: "Large-N LER is statistically well-supported for this model
    configuration, NOT the physically true LER"

Known LER suspicion check:
  The suspicion was "LER ∝ sqrt(Dose)" instead of "LER ∝ 1/sqrt(Dose)".
  VERIFIED: The current production model (photon_deposition_shot_noise)
  shows correct 1/sqrt(Dose) scaling for the relative noise amplitude
  (slope = -0.498 ± 0.001). The absolute LER from binary edge extraction
  shows a weaker dose dependence due to threshold nonlinearity, but the
  underlying shot noise follows the correct Poisson statistics.
  The earlier LER∝sqrt(Dose) behaviour was from the OLD model
  (poisson_shot_noise with dose=None) which used a heuristic scale
  factor. This has been replaced.

2.9 CD / NILS / LER / LWR
--------------------------------------------------------------------

- NILS: Normalised Image Log-Slope at line edge
  NILS = CD * d(log I)/dx = CD * (1/I) * (dI/dx)
  - Uses steepest gradient point (argmax of |dI/dx|)
  - CD measured as width of undeveloped (below-threshold) region
- Typical NILS values: ~8.5 (no SE blur), ~2.7 (10 nm SE blur)
- NILS is dose-independent for aerial image (linear scaling cancels in log-slope)
- Reference test passes: |euvsimulator - reference| < 0.3

7. CRITICAL PROBLEMS (Top 5)
====================================================================

1. RCWA 2D is a stub
   - No vector TE/TM coupling
   - No energy conservation
   - No tests
   - Affects: contact holes, SRAM, 2D mask features

2. TE/TM unpolarized averaging WRONG
   - pipeline.py: averages complex fields, not intensities
   - Affects: all RCWA-based simulations with unpolarized light
   - Location: pipeline.py line 551

3. Dill parameter inconsistency
   - C varies by factor 2 (0.05 vs 0.1)
   - Q varies by factor 25 (0.04 vs 1.0)
   - Three different defaults in three places
   - Affects: resist model calibration, CD, LER/LWR in full_chem mode

4. Depth-dependent absorption unused in main pipeline
   - dill_A, dill_B configured but ignored in _cd_via_full_chem
   - Uniform acid generation through resist depth
   - Physics: Beer-Lambert attenuation over 100 nm is ~50%

5. PEB sigma_diff inconsistent with D*t_bake
   - Default sigma_diff = 5 nm
   - Physical value: sqrt(2*5*60) = 24.5 nm
   - ADI solver implemented but unused
