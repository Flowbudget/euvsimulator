2. BEGRÜNDUNG DER ÄNDERUNGEN
============================================================
Audit 5.2B.1 (Q7): Die 256-Vielfachheits-Anforderung ist KEINE
physikalische Notwendigkeit — das Aerial-Feld ist exakt y-invariant
(max|aerial[y+1]-aerial[y]| = 0, bitweise). Die Einschränkung stammte
ausschließlich aus der tile-Konstruktion (ganzzahliger Faktor).

Neue Konstruktion (repeat + trim): Für jedes N wird der
deterministische dose_map auf ceil(N/256) Kacheln erweitert und auf
N Zeilen abgeschnitten. Mathematisch gerechtfertigt, weil alle Zeilen
bitweise identisch sind → der Y-circular-Blur-Wrap verbindet für
JEDES N konsistent identische Zeilen (kein künstlicher Rand).

Das Rauschen wird NIE getiled/wiederholt: Poisson wird auf dem
erweiterten deterministischen Feld generiert (jede Zeile eigenes
unabhängiges Rauschen).
