============================================================

- RCWA path (use_rcwa=True) with 11 orders

| TM-only       | 50,009        | ~10^9      | 6.330|
| Field-avg (current) | 12,503   | ~6×10^8    | 6.330|
| Intensity-avg (correct) | 25,005 | ~5×10^9    | 6.330|

ABWEICHUNG:
- TE intensity is ~400,000× SMALLER than TM!
- Current field-average: (E_TE + E_TM)/2
- Correct for unpolarized: I = (|E_TE|² + |TM|²)/2

INTERPRETATION:
- RCWA solver produces PHYSICALLY IMPLausible results:
  - TM reflectivity > 1 (10^5-10^9 intensity!)
  - TE reflectivity ~10^-4
  - Energy conservation violated
- Default pipeline uses THIN-MASK ANALYTIC path (use_rcwa=False)
  where TE=TM (no polarization split)
- RCWA path is BROKEN and should NOT be used

BUG: JA – P0
- RCWA TM solver produces non-physical gain
- Field-averaging is wrong for unpolarized light
- Default path avoids this bug by not using RCWA

PRIORITÄT: P0 (falls RCWA genutzt wird) / P2 (Default-Pfad okay)
EMPFEHLUNG: RCWA-Pfad reparieren oder deaktivieren, bis validiert

BUG: JA – P1
- sigma=0 → Division by Zero in TCC = 2*J1(x)/x bei x=0
- Physikalisch: σ=0 = voll kohärent → TCC(dm) = 1 für ALLE dm
- Limit x→0: 2*J1(x)/x → 1 (da J1(x) ~ x/2)
- Aktuelle Implementierung behandelt x=0 nicht

PRIORITÄT: P1
EMPFEHLUNG: In _j1(x) oder TCC-Berechnung: if x < 1e-12: return 1.0
