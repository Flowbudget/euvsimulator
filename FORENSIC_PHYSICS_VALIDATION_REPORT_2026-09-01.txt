8. GATE E — AERIAL / NILS / CD  plus CD-METHODEN-AUDIT
--------------------------------------------------------------------------------

8.1 Was die Pipeline wirklich als CD ausgibt  [PROVEN]

  Datei: pipeline.py  _cd_via_aerial_threshold
  threshold = resist_threshold_norm * mean(aerial) * (20.0 / dose)
  Default resist_threshold_norm = 0.5, dose = 20 -> threshold = 0.5 * mean.

  Standardbenchmark 64/32 nm, NA=0.33, sigma=0.8, grid=256,
  resist_model=aerial_threshold, se_blur=0, use_rcwa=False:

    aerial min / mean / max = 0.477 / 4.775 / 11.645
    (nach dose-Skalierung, Einheit "mJ/cm2 * Intensitaet")
    threshold_pipeline = 2.387
    CD_pipeline         = 27.50 nm     (Pixel-Run, dx=0.25 nm)
    CD interpoliert an Threshold-Kreuzungen = 27.62 nm

  Das ist OPTICAL CD bei einem willkuerlichen, aber definierten
  Intensitaetsschwellwert. Es ist NICHT:
    - Mask-CD (32 nm)
    - Resist-developed CD
    - SEM-CD

  Die 20.0 in der Threshold-Formel ist hardcodiert (nicht cfg.dose).
  Bei dose != 20 skaliert der Threshold mit 20/dose, die Aerial
  skaliert mit dose: Netto-Effekt ist beabsichtigte Dosisabhaengigkeit.
  ASSUMPTION: nominal_dose=20 ist der Anker, nicht eine Physikkonstante.

8.2 Was nils() intern als CD verwendet  [PROVEN]

  Datei: aerial/abbe.py nils()
  thr_nils = (Imin + Imax) / 2 = 6.061
  "CD" intern = laengste Region unter diesem thr = 40.0 nm
  Steilster Gradient: Pixel 43, I=6.80, |dI/dx|=0.701 /nm
  ILS = |dI/dx|/I = 0.1031 /nm
  NILS_reported = 0.1031 * 40.0 = 4.124

  Der steilste Gradient liegt NICHT an der Pipeline-Kante.
  Pipeline-Kante: Pixel ~72.25 und ~182.75, I = threshold = 2.387
  ILS dort = 0.1799 /nm
  NILS_Mack am gedruckten Rand, CD=27.5:  0.1799*27.5 = 4.95
  NILS_Mack mit nominal 32 nm:            0.1799*32   = 5.76

  Folge: Das gemeldete nils_value=4.12 mischt
    (a) ILS am falschen Ort (Max-|dI/dx|, nicht Threshold-Kante)
    (b) CD aus (Imin+Imax)/2 = 40 nm, nicht Pipeline-CD 27.5 nm

  Mack 1987 Definition (Standard Lithographie):
    NILS = w * d(ln I)/dx  ausgewertet an der Feature-Kante.
  Die aktuelle Funktion erfuellt das nicht.

8.3 Synthetische Profile (Methodenvergleich)

  Ideal 32 nm dunkle Linie, I=0.2/1.0:
    (Imin+Imax)/2 CD = 32.0 nm
    mean-threshold CD = 32.0 nm

  Moegliche Ursache des alten Claims: anderes Feld, anderes Grid,
